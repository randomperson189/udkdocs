Unreal Developer Network

Unreal Developer Network (Unreal デベロッパーネットワーク) は、数々の受賞歴に輝く「Unreal Engine」リアルタイムテクノロジーを利用するライセンシーおよび MOD 開発者のための公式サポートサイトです。エンジンのライセンシーと「Unreal Development Kit」のユーザー両方が対象となります。

米国以外にお住まいの開発者の方は、以下の東アジア ミラーサイトをご利用になると、快適な速度を得られる場合があります。 ( http://udn.epicgamesjapan.com および http://udn.epicgameskorea.com )

業界ナンバーワンのゲームエンジンをマスターし、直感的なツール群を使用することによって、没入体験、エキサイティングなゲームプレイ、素晴らしい背景を創り出すために必要となるすべてのスキルを学ぶことができます。

強力でフレキシブルなゲームエンジンとツール群を使用することによって、前世代のハードウェア構成とプラットフォームで稼働するゲームを作成するために必要となるスキルを学ぶことができます。

Epic、「Unreal Engine 3」による Flash のサポートを発表
2011年10月4日
Epic Games の創始者であり、最高経営責任者と技術ディレクターを兼任する Tim Sweeney 氏は本日、Adobe MAX 2011 で基調講演を行い、数々の受賞歴を誇る同社の「Unreal Engine 3」 (UE3) テクノロジーが Adobe® Flash® ベースの環境内で完全に動作するようになったことを発表しました。

Unreal University、MIGS にて 2011年開講
2011年9月23日
Unreal University は、Epic Games 社と Autodesk 社が後援している教育プログラムです。Unreal Development Kit (UDK) を含む「Unreal Engine 3」テクノロジーを学ぶことに関心がある人々に対して、専門的で実地のガイダンスを提供しています。講演への参加は無料です。その内容には、レベルデザインのベストプラクティス、モバイル ゲームの開発に関するヒントとコツなどが含まれています。

Epic Games、「Unreal Engine 3」と UDK による iOS のサポートを発表
2010年12月16日
Epic Games, Inc. は、Apple 社の iOS オペレーティングシステム上でゲームを作成するためのサポートが、「Unreal Engine 3」と Unreal Development Kit に含まれるようになったと発表しました。数々の受賞歴に輝く「Unreal Engine 3」と「Unreal」エディタ、Kismet、Matinee 等の主要ツール群を使用して、モバイル用アプリケーションを作成することができるようになりました。

本サイトおよび Epic 社の「Unreal Engine」をサポートする他のアウトレット (Unreal Developer Network ウェブサイトおよびメーリングリストなどが含まれますが、これに限定されません) に情報を提供することによって、貴殿、および、貴殿の会社の従業員、受託者、サブライセンシー、代表者が投稿した情報が、 Epic 社の独占所有物になるということに貴殿が同意したことになります。
