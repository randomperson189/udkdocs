벌크(대량) 임포터

문서 변경내역: Matthew Kuhlenschmidt 작성. Mike Fricker 업데이트.

개요

대량 가져오기 도구는 통 재귀를 해당 경로내의 디렉터리 구조를 통해 실행하여 지정된 디렉터리 경로로 모든 파일 가져오기를 실행합니다. 본 도구는 자동으로 패키지와 그룹을 생성하고 디렉터리 구조가 배치된 양식에 따라 올바른 패키지로 파일을 배치합니다.

참고: 현재 대량 가져오기 도구는 특정 언어의 오디오 파일의 대량 가져오기 실행에만 주로 사용 가능하지만 가져오기할 수 있는 파일의 유형에는 제한이 없습니다(UE3로 가져오기될 수 있는 한).

시작하기

대량 가져오기 도구를 시작하려면 간단한 2가지 절차를 따라야 합니다.

  1. 가져오기하고 싶은 파일을 올바른 디렉터리 구조 형식으로 셋업합니다.
  2. Unreal 편집기내에서 대량 가져오기 과정을 시작합니다.

디렉터리 구조 셋업하기

디렉터리 구조를 셋업하려면 가져오기하고 싶은 파일을 windows 익스플로러내의 다음 구조에 배열하십시오.

  • BaseName(기본 이름) (필수 폴더). --가져오기가 완료되면 콘텐츠 브라우저 패키지 트리는 GameName\Content\BaseName이라고 명명된 폴더를 포함하게 됩니다.
    • SubName(하위 이름) (필수 폴더). --가져오기가 완료되면 콘텐츠 브라우저 패키지 트리는 GameName\Content\BaseName\SubName이라고 명명된 폴더를 포함하게 됩니다.
      • PackageName(패키지 이름) (필수 폴더). --가져오기가 완료되면 콘텐츠 브라우저 패키지 트리는 GameName\Content\BaseName\SubName\PackageName이라고 명명된 폴더를 포함하게 됩니다.
        • GroupName(그룹 이름) (선택 폴더). --가져오기가 완료되면 GroupName은 위의 PackageName.아래에 그룹으로 표시됩니다.
          • file1.ext (선택 파일). --이 레벨은 위의 Package 와 Group 구성으로 가져오기될 특정 에셋을 포함합니다.
          • file2.ext (선택 파일)
          • ...
        • file3.ext (선택 파일). --이 레벨에서 선택적으로 파일을 지정할 수 있습니다. 그룹으로 가져오기되지 않지만 위의 패키지로 가져오기됩니다.
        • ...

참고:

  • 디렉터리 구조내에서는 하위 폴더, 패키지, 또는 그룹 숫자에 제한이 없습니다.
  • 최소 1개의 파일은 반드시 패키지 디렉터리내에 포함되야합니다. 그렇지 않으면 해당 패키지는 저장되지 않습니다.
  • GroupName 레벨 아래의 폴도는 무시되지만 파일에 대해 여전히 재귀되어집니다.
  • PackageName 또는 GroupName 레벨 아래에 있지 않은 파일은 무시됩니다.
  • 그룹 디렉터리는 선택 사항입니다. 파일은 패키지 디렉터리 레벨에서부터 가져오기될 수 있습니다.
  • 패키지 이름, 그룹 이름, 파일 이름은 빈칸, 마침표(.), 슬래시(\,/), 콜론(:), 느낌표(!), 또는 쉼표(,)를 포함할 수 없습니다. 모든 위반자는 무시되고 위반 사항을 설명한 메시지가 로그 창에 작성됩니다.

예제

예제 1

디렉터리 구조 레이아웃이 다음과 같은 경우 "C:\Sounds\DEU\A_Announcer_Reward_deu\Rewards\A_RewardAnnouncer_Assassin.wav"

A_Announder_Reward_deu.upk로 명명된 패키지가 Rewards라 불리는 그룹을 사용하여 작성됩니다. A_RewardAnnouncer_Assassin은 그룹내에서 USoundNodeWave 에셋입니다. 패키지는 게임 고유의 Content 디렉터리내의 \Sounds\DEU에 저장됩니다.

예제 2

다음 왼쪽은 가상의 디렉터리 구조이고, 오른쪽은 대량 가져오기가 완료된 후의 콘텐츠 브라우저에서의 모습입니다.

벌크 임포트 프로세스 시작하기

  1. 대량 가져오기 과정을 시작하려면 콘텐츠 브라우저 패키지 트리내의 아무 곳이나 마우스 오른쪽 버튼으로 클릭한 다음 Bulk Import...를 선택하십시오. 디렉터리를 선택하라고 메시지가 담긴 창이 나타납니다.
    • 주의: 어디를 클릭하든 무엇을 선택하든 상관이 없지만 패키지는 디렉터리 구조에 따라 전적으로 저장됩니다.
  2. BaseName 디렉터리를 선택하십시오. BaseName 디렉터리 위 또는 아래의 어떠한 디렉터리도 선택하지 마십시오. 그렇게 하면 잘못된 대량 가져오기를 초래할 수 있습니다.
    • BaseName 디렉터리는 대량 가져오기에 대해 디렉터리 구조가 시작되는 곳이라는 것을 기억하십시오. 이 이름을 가진 폴더는 \GameName\Content 디렉터리에 작성되고 콘텐츠 브라우저에 표시될 것입니다.
  3. 가져오기할 검색된 파일의 수가 안내됩니다. Yes(예)를 선택하여 계속 진행합니다.
  4. 가져오기할 각 파일 유형에 대한 팩토리 설정을 이제 설정할 수 있습니다. 가져오기 대화 상자에서 ALL에 대해 OK를 누르면, 선택한 팩토리 설정은 해당 팩토리 설정이 가져오기할 수 있는 모든 파일로 전파됩니다. 새로운 팩토리 설정(예: 가져오기할 수 있는 각기 다른 파일 유형)이 검색될 때마다 새 설정을 선택하는 안내 메시지가 표시됩니다.
    • 예를 들면 다음과 같습니다. 사운드 파일(.wav) 및 텍스처 파일(.tga)를 가져오기할 경우, 2개의 파일이 각기 다른 설정을 필요로 하기에 Sound Factory 대화 상자 창과 Texture Factory 대화 상자 창이 나타납니다.
  5. 일단 해당 과정이 완료되면 과정 중에 발생한 오류에 대해 통지받을 것입니다. Unreal Editor 에서의 로그 탭은 자세한 오류 목록을 제공합니다.

참고:

  • 올바른 디렉터리 및 패키지 레이아웃을 셋업하려면 제작된 모든 패키지는 반드시 저장되어야 합니다. 해당 패키지가 디스크에 저장되기 때문에 일단 완료되면 해당 작업을 실행 취소할 수 없습니다.
  • 디렉터리 구조가 이미 존재하는 패키지 이름을 포함하는 경우, 패키기에 가져오기한 해당 파일은 이미 존재하는 패키지와 병합되어 올바른 디렉터리 레이아웃을 초래하지 않을 수 있습니다. 아주 잘 알지 않는 한 완전히 새로운 패키지로 가져오기하는 것이 최선의 방법입니다.
