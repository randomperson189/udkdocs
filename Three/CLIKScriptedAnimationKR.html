ActionScript 나 UnrealScript 에서 tween 애니메이션 만드는 법

문서 변경내역: James Tan 작성. 홍성진 번역.
  • ActionScript 나 UnrealScript 에서 tween 애니메이션 만드는 법
    • ActionScript 에서 애니메이션 tween
    • UnrealScript 에서 애니메이션 tween

주: 예기치 못한 결과가 나올 수 있으니, 타임라인 애니메이션과 ActionScript tween 을 섞어 쓰지 마시기 바랍니다.

ActionScript 에서 애니메이션 tween

ActionScript 
_global.gfxExtensions = true; // 이 줄은 (3D 공간의) Z 축으로 tween 하려는 경우에만 필요합니다.
import gfx.motion.Tween;
import mx.transitions.easing.*;

Tween.init(); // 이 줄은 모든 무비 클립에 tween 함수성을 추가합니다.

MyMovieClip.tweenTo(3, {_x:250, _y:250, _z:-5000, _alpha:50}, Strong.easeOut);

  • tweenTo() - 스테이지상의 오브젝트 위치에서 코드의 프로퍼티로 지정된 위치로 tween 합니다.
    • 초 단위 기간
    • 목적지 X 가 들어있는 오브젝트
    • 목적지 Y 가 들어있는 오브젝트
    • 목적지 Z 가 들어있는 오브젝트
    • 알파
    • 등등
    • Tween 종류와 메서드
      • Tween 종류
        • Back 뒤로
        • Bounce 튕김
        • Elastic 탄력
        • Regular 보통
        • Strong 강조
        • None 없음
      • Tween 메서드
        • easeIn 서서히 등장
        • easeOut 서서히 퇴장
        • easeInOut 서서히 등장후 퇴장
  • tweenFrom() - 코드에 주어진 프로퍼티 위치에서 스테이지 상의 오브젝트 위치로 tween 합니다.
    • 초 단위 기간
    • 출발지 X 가 들어있는 오브젝트
    • 출발지 Y 가 들어있는 오브젝트
    • 출발지 Z 가 들어있는 오브젝트
    • 알파
    • 등등
    • Tween 종류와 메서드
      • Tween 종류
        • Back 뒤로
        • Bounce 튕김
        • Elastic 탄력
        • Regular 보통
        • Strong 강조
        • None 없음
      • Tween 메서드
        • easeIn 서서히 등장
        • easeOut 서서히 퇴장
        • easeInOut 서서히 등장후 퇴장
  • tweenEnd() - tween 끝으로 점프하여 즉시 끝냅니다.

UnrealScript 에서 애니메이션 tween

Unrealscript 
TweenTo(ArsenalMC, 0.5, "_z", -1500.0, TWEEN_EaseOut, "SomeFunction");

  • TweenTo() - 스테이지 상의 오브젝트 위치에서 코드의 프로퍼티에 주어진 위치로 tween 합니다.
    • 무비클립 리퍼런스는 GFxObject 로
    • 초 단위 기간은 float 로
    • tween 할 프로퍼티는 string 으로
    • tween 해 갈 값은 float 로
    • tween 유형은 constant 로
    • (옵션) 종료시 실행할 함수는 string 으로
