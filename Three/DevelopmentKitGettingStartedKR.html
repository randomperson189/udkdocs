개요

Unreal Development Kit 은 사용자 지정 아트, 레벨, 코드의 조합을 사용하여 매우 다양한 사용자 지정 3D 어플리케이션을 제작하는데 필요한 모든 도구를 제공합니다. UDK 는 저희가 Unreal Engine 에 새 기능을 추가함에 따라 자주 업데이트 됩니다. UDK 에는 콘텐츠 및 레벨 가져오기와 작성하기에 사용되는 언리얼 에디터, 어플리케이션의 쿠킹, 시동, 패킹에 사용되는 Unreal Frontend, 3DS Max, Maya 및 기타 다른 콘텐츠 작성용 어플리케이션으로부터 메쉬 및 애니메이션 가져오기에 사용되는 Actor X 가 포함되어 있습니다. UDK 의 시스템 요구 사양 은 상당히 합리적입니다.

프로그래머

Unreal Development Kit 의 코드 개발에는 게임 개발을 위한 특별 기능을 갖춘 매우 강력한 객체 지향 프로그래밍 언어인 UnrealScript 프로그래밍 언어를 사용합니다. UDK 를 사용한 프로그래밍 시작하기에 대한 보다 자세한 정보는 UDK 프로그래밍 페이지를 참고하십시오.

또한 좀 더 깊이 있는 정보를 원한다면 UDK 기술 및 프로그래밍 홈 을 방문해 주십시오.

콘텐츠 제작 – 아티스트, 애니메이션 제작자, 레벨 디자이너, 오디오 전문가

레벨 디자이너는 기존의 콘텐츠뿐만 아니라 아티스트에 의해 작성된 것 또는 Unreal 로 가져오기된 사용자 지정 콘텐츠를 사용하여 새 월드를 작성하는데 언리얼 에디터 를 사용합니다.

아티스트 및 애니메이션 제작자 또한 대부분의 작업에언리얼 에디터 를 사용합니다. 사용자 지정 텍스처는 에디터를 사용하여 가져오기 되며, 사용자 지정 재질은 UnrealEd 에 포함된 재질 편집 도구를 사용하여 작성됩니다. 사용자 지정 메쉬 및 애니메이션은 Actor X 를 사용하여 가져오기 됩니다.

사용자 지정 아트 및 오디오의 작성 및 가져오기를 비롯하여, UDK 를 사용한 레벨 작성 시작하기에 대한 좀 더 자세한 정보는 UDK 콘텐츠 작성 페이지를 참고하십시오.

좀 더 깊이있는 정보를 원하시면 콘텐츠 작성 홈페이지 와 레벨 작성 홈페이지 를 방문해 주십시오

지원 - 문서와 포럼

최신 UDK 버전 정보는 UDK 빌드 노트 를 참고하십시오.

UDK를 사용하시는 mod 개발자라면, UDN을 통해 어느 정도의 문서와 튜토리얼은 물론, 게임 개발과 에픽이 개발한 게임에 관련된 참고 머티리얼에도 접근해 볼 수 있으십니다.

알림: UDN 오프라인 버전은 현재 지원되지 않습니다. UDN 긁어가기는 누구에게도 허용되지 않습니다. 이런 행위는 사이트를 매우 느리게 만들어 다른 사이트 방문자의 사용감에 악영향을 끼치게 됩니다.

튜토리얼을 제출하시려거든 다음 이메일을 통해 연락을 주시기 바랍니다: tutorialsubmissions@epicgames.com. UDN과 포럼을 훑어본 이후에도 어떤 정보가 필요하신 경우, UDN에 해당 정보를 올려달라 요청하실 수 있습니다. 우선권이 허용되는 한 새 페이지가 제작될 것입니다. 다른 용도의 커뮤니케이션에는 이 채널 사용을 자제해 주시기 바랍니다.

UDK 포럼 을 통해 질문, UDK 기능 요청 및 토론 등을 하실 수 있습니다. UDK 커뮤니티 구성에 도움이 되는 공헌은 언제든 대 환영입니다!

별도의 요청이 없는 한 UDN에 직접 메일을 보내지 말아 주시기 바랍니다.

별도의 요청이 없는 한 에픽 직원에게 직접 메일을 보내지 말아 주시기 바랍니다.

Mastering Unreal Technology 책 시리즈와 VTM도 주의깊게 살펴 봅시다!

새 빌드로 옮겨가는 데 도움이 필요하시다면 새 빌드 작업방식 페이지를 참고해 보십시오!
