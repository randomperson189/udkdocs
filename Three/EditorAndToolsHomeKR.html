언리얼 에디터와 툴

언리얼 엔진 3에는 레벨 제작과 편집, 아트 애셋 임포트와 정리, 전문 콘텐츠 애셋 제작 등등의 작업에 사용되는 툴이 포함되어 있습니다. 이 툴의 중추가 되는 부분은 언리얼 에디터 또는 UnrealEd 라고도 합니다. 언리얼 에디터는 레벨 에디터, 브라우저 모음, 전문 툴 세트로 구성되어 있습니다.

사실상 프로젝트 작업을 하는 개발자가 언리얼 에디터 자체로 작업하는 시간은 극히 일부입니다. 레벨 디자이너는 레벨 에디터를 사용하여 게임이 벌어지는 월드와 배경을 만들 테고, 콘텐츠 제작자는 애셋을 임포트하고 전문 툴을 사용하여 게임에서 사용할 수 있도록 셋업할 것입니다. 프로그래머는 테스트 레벨을 사용하여 게임코드가 예상한 대로 돌아가는지를 확인하고 에디터의 기능을 확장하거나 새 툴을 추가하는 작업을 하게 될 수도 있습니다.

그래도 이 모든 것이 언리얼 에디터를 통해 연결되기에, 언리얼 엔진 3 로 작업하는 개발자는 누구든 언리얼 에디터와 그 툴에 익숙해 질 필요가 있습니다.

  • Main Editor Toolbox KR 메인 에디터 툴박스 - 언리얼 에디터 툴박스 툴 참고서입니다.
  • Editor Buttons KR 에디터 버튼 - 언리얼 에디터 콘트롤 참고서입니다.

브라우저

언리얼 에디터에는 매우 세분화된 기능별로 별도의 창으로 되어 있는 브라우저 모음이 포함되어 있습니다. 모든 브라우저가 도킹되어 탭으로 표시되는 메인 브라우저 창이 기본입니다. 브라우저의 기능성은 일반적으로 현재 에디터에 열려있는 맵에 특정됩니다.

브라우저 창은 메인 툴바의 버튼을 클릭하면 표시됩니다. 특정 브라우저는 메인 메뉴의 보기 > 브라우저 서브메뉴에서 직접 열어볼 수 있습니다.

브라우저 토픽
  • Actors Browser Reference KR 액터 브라우저 참고서 - 맵에 추가시킬 액터 클래스 목록입니다.
  • Attachments Browser Reference KR 어태치먼트 브라우저 참고서 - 액터간 어태치먼트(attachment, 붙이기) 상황을 시각적으로 보여주는 에디터입니다.
  • Content Browser Reference KR 콘텐츠 브라우저 참고서 - 콘텐츠 애셋 제작, 확인, 변경용 브라우저입니다.
  • Layers Browser Reference KR 레이어 브라우저 참고서 - 맵에 있는 액터를 레이어로 묶어 체계적으로 정리하면 선택, 표시를 쉽게 관리할 수 있습니다.
  • Level Browser Reference KR 레벨 브라우저 참고서 - 퍼시스턴트(지속) / 스트리밍 레벨을 나열하여 선택, 편집, 표시를 쉽게 관리할 수 있습니다.
  • Scene Manager Reference KR 씬 매니저 참고서 - 현재 레벨의 모든 액터를 나열하여 선택과 프로퍼티 편집을 쉽게 할 수 있습니다.
  • Referenced Assets Browser Reference KR 리퍼런스된 애셋 브라우저 참고서 - 선택된 액터가 리퍼런스하는 애셋을 표시합니다.
  • Texture Stats Browser Reference KR 텍스처 통계 브라우저 참고서 - 텍스처 사용 관련 정보를 표시합니다.

에디터 툴

에디터 툴이란 언리얼 에디터 안에 포함되긴 했으나 맵 편집 프로세스와는 별도인 에디터를 말합니다. 이러한 툴은 일정한 애셋 타입에 일정한 작업을 해 주는 별개의 창입니다.

보통 편집할 애셋에 더블클릭하거나 우클릭한 후 맥락 메뉴에서 적절한 에디터로 애셋을 여는 옵션을 선택하면, 그에 맞는 툴에 그 애셋이 편집가능한 상태로 열리게 됩니다.

에디터 툴 토픽
  • AnimSet Editor User Guide KR 애님세트 에디터 - 스켈레탈 메시, 애니메이션, 모프 타겟 편집 툴입니다.
  • Anim Tree Editor User Guide KR 애님트리 에디터 - 애니메이션 트리를 통한 애니메이션 블렌딩 편집 툴입니다.
  • Asset Consolidation Tool KR 애셋 통합 툴 - 중복된 동일 애셋 여럿을 하나로 통합하는 기능을 하는 툴입니다.
  • Reference Tree Tool KR 리퍼런스 트리 툴 - 애셋이 리퍼런스하는 애셋을 보여주는 툴입니다.
  • Bulk Import KR 벌크 임포트 - 언리얼 에디터로 대량의 콘텐츠를 임포트하는 법 안내입니다.
  • Cascade User Guide KR 캐스케이드 - 파티클 이펙트 편집 툴입니다.
  • Kismet User Guide KR 키즈멧 - 비주얼 스크립팅 노드-기반 네트워크를 통한 게임플레이 제작 툴입니다.
  • Material Editor User Guide KR 머티리얼 에디터 - 노드-기반 네트워크를 통해 표면에 적용할 셰이더 제작 툴입니다.
  • Material Instance Editor User Guide KR 머티리얼 인스턴스 에디터 - 파라미터로 구동되는 머티리얼 인스턴트 편집 툴입니다.
  • Matinee User Guide KR 마티네 - 맵의 게임플레이와 시네마틱에 쓰이는 애니메이션 시퀸스 제작 툴입니다.
  • PhAT User Guide KR 피직스 애셋 툴 - 스켈레탈 메시에 쓰이는 리짓 바디 피직스 셋업 툴입니다.
  • Post Process Editor User Guide KR 포스트 프로세스 에디터 - 노드-기반 네트워크를 통한 포스트 프로세스 비주얼 이펙트 제작 툴입니다.
  • Static Mesh Editor User Guide KR 스태틱 메시 에디터 - 스태틱 메시, 콜리전, UV 편집 툴입니다.
  • SoundCue Editor User Guide KR 사운드큐 에디터 - 노드-기반 네트워크를 통한 순차 사운드 애셋 제작 툴입니다.
  • Landscape KR 랜드스케이프 - 야외 환경 제작용 터레인 편집 툴입니다.

엔진 툴

엔진 툴은 에디터 외부 어플리케이션이며, 개발 파이프라인에서 여러가지 용도로 사용됩니다.

엔진 툴 토픽
  • Unreal Console KR 언리얼 콘솔 - UnrealConsole 툴 사용 안내입니다.
  • UnrealFrontend KR 언리얼 프론트엔드 - UnrealFrontend (예전 CookerFrontEnd) 유틸리티 사용 안내입니다.
