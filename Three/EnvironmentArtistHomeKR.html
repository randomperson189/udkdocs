배경 아티스트

배경 아티스트라면 레벨 디자이너가 월드를 만들고 그 안에 채워넣기 위해 필요한 콘텐츠, 즉 배경(environment)을 만들어 주는 것이 일이라 하겠습니다. 배경 아티스트는 건축물이나 기계같은 것에서 땅바닥의 잔해나 초목에 이르기까지, 폭넓은 범위의 오브젝트 제작 임무를 맡게 될 수가 있습니다. 보통 텍스처를 포함한 스태틱 메시로 사용할 모델 제작 작업인데, 그 메시에는 머티리얼을 적용시킬 수도 있습니다.

언리얼 엔진 3 는 콘텐츠를 엔진으로 가져오는 데 쓸 유연한 파이프라인은 물론, 퍼포먼스 희생 없이도 미려한 배경 제작이 가능하도록 콘텐츠를 셋업하고 사용하고 최적화시킬 수 있는 툴을 여럿 제공하고 있습니다.

  • FBX 콘텐츠 파이프라인
    FBX 파이프라인을 사용하여 UE3 용 콘텐츠를 만들고 임포트하는 법에 대한 기술적인 문서와 튜토리얼입니다. 스태틱 메시 - 스켈레탈 메시 - 머티리얼 - 애니메이션 - 모프 타겟.

시작하기 토픽
  • Getting Started Content KR - UE3 용 콘텐츠 제작의 첫걸음 입니다.
  • Design Workflow KR - 에픽의 내부 디자인 작업방식에 대한 개요입니다.

콘텐츠 제작 토픽
  • Creating Models KR - UE3 용 모델 제작에 필요한 아트 애셋에 대한 설명입니다.
  • PivotPainter Tool KR 피벗 페인터 툴 - 모델의 버텍스 데이터에 모델 피벗과 로테이션 정보를 보관하는 툴입니다.
  • FBX Static Mesh Pipeline KR - FBX 포맷을 사용하여 스태틱 메시를 만들고 임포트하는 법에 대한 안내입니다.
  • Importing Static Mesh Tutorial KR - 스태틱 메시를 만들고 임포트하는 법에 대한 튜토리얼입니다.
  • Light Map Unwrapping KR - 라이트맵과 함께 사용할 UV 셋업 관련 우수 사례입니다.
  • Normal Map Processing KR - 언리얼 엔진 3 에서 사용할 노멀 맵을 제대로 처리하는 법입니다.
  • Modular Environment Creation KR - 모듈식 배경에 사용할 메시 디자인 안내서입니다.
  • Static Mesh Editor User Guide KR - 언리얼 에디터 내 스태틱 메시 에디터 사용 안내서입니다.
  • Mesh Simplification Tool KR - 언리얼 에디터 안에서 파라미터형태로 단순화된 메시를 만드는 법 안내서입니다.
  • Fracture Tool KR - 프랙처 스태틱 메시를 만들고 사용하는 법 안내서입니다.
  • Collision Reference KR - 스태틱 메시와 다른 지오메트리 종류에 대한 콜리전 타입 참고서입니다.
  • Collision Technical Guide KR 콜리전 테크니컬 가이드 - 언리얼 엔진 3 안에서 콜리전이 어떻게 작동하는가에 대한 기술적 안내서입니다.
  • Creating Textures KR - 노멀 매핑된 머티리얼과 함께 사용할 텍스처 제작 팁입니다.
  • Importing Texture Tutorial KR - 텍스처를 언리얼 엔진 3 에 들여오는 법입니다.
  • Creating Normal Maps KR - 노멀 맵 제작에 있어서의 실전적인 조언과 자료입니다.
  • Creating Shade Maps KR - 3dsMax 를 사용하여 셰이드 맵을 만드는 법 안내입니다.

관련 토픽
  • Massive LOD KR - UE3 에서 탁 트이는 경치를 만들기 위한 Massive LOD 시스템 사용 안내입니다.
  • Procedural Buildings KR - 순서를 지정하여 건물을 만드는 (프로시저럴 빌딩) 시스템에 대한 개요입니다.
  • APEX Destruction KR - APEX 를 사용하여 UE3 에서 파괴가능 배경을 만드는 법입니다.
  • Content Profiling Home KR - 콘텐츠의 퍼포먼스를 극대화시키기 위한 팁입니다.

모바일 토픽
  • Designing For Mobile KR - 모바일 디바이스에서 돌릴 콘텐츠 디자인에 관련된 팁과 꼼수입니다.
  • Mobile Material Reference KR - 모바일 머티리얼 제작에 참고할 매뉴얼입니다.
  • Mobile Texture Reference KR - 모바일 디바이스 상의 텍스처 처리 관련 정보입니다.
