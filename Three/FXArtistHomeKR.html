FX 아티스트

FX 아티스트는 실제세계, 가상세계는 물론 게임에서 사용할 극적인 효과를 재구성하는 역할을 담당합니다. 예를 들면 무기에서 발사되는 탄환(projectile)과 그 자욱, 폭발, 마법 주문, 검강 효과 등이 FX 아티스트가 담당하게 될 이펙트입니다. 이러한 이펙트는 일반적으로 파티클과 머티리얼을 사용하여 생성됩니다. FX 아티스트는 파티클 시스템과 머티리얼 시스템에 대한 개념을 확실히 잡고 있어야 하며, 월드에 현실감을 내기 위해 어떤 것을 어떻게 조합시켜 원하는 결과를 낼 수 있을지 확실히 알고 있어야 합니다.

파티클과 이펙트 일반 토픽
  • Cascade User Guide KR 캐스케이드 사용 안내서 - UE3 의 파티클 시스템 에디터에 대한 사용 안내서입니다.
  • Particle System Reference KR 파티클 시스템 참고서 - 모든 파티클 시스템 모듈에 대한 완벽 정리집입니다.
  • Distributions KR 디스트리뷰션(분포) - 파티클 프로퍼티에 사용되는 분포 데이터형에 대한 개요입니다.
  • Lens Flare Editor User Guide KR 렌즈 플레어 에디터 사용 안내서 - UE3 의 렌즈 플레어 에디터에 대한 사용 안내서입니다.
  • VFX Optimization KR VFX 최적화 - UE3 의 비주얼 이펙트 최적화 기법입니다.

파티클과 이펙트 콘텐츠 제작 토픽
  • Particle Examples KR 파티클 예제 - 약간의 파티클 사용법에 대한 분석입니다.
  • Particle Sprite SubUV Emitter Tutorial KR 파티클 SubUV 튜토리얼 - 애니메이션에 대해 SubUV 이미지를 선택하여 이미터를 만드는 법입니다.
  • Fake Mesh Lighting KR 페이크 메시 라이팅 - 머티리얼을 사용하여 메시와 파티클에 가짜 라이팅을 비추는 법입니다.
  • Anim Trails KR 애님 트레일 - AnimNotify 로 구동되는 트레일 파티클을 만드는 법입니다.
  • Per Actor Particle Collision KR 액터별 파티클 콜리전 - 액터별 파티클 콜리전 이벤트 셋업하기 입니다.
  • Using Instance Parameters KR 인스턴스 파라미터 사용하기 - 파티클 시스템에 인스턴스 파라미터 셋업하기 입니다.

머티리얼 일반 토픽
  • Material Editor User Guide KR 머티리얼 에디터 사용 안내서 - UE3 의 노드 기반 머티리얼 에디터에 대한 개요입니다.
  • Material Instance Editor User Guide KR 머티리얼 인스턴스 에디터 사용 안내서 - UE3 의 머티리얼 인스턴스 에디터에 대한 개요입니다.
  • Instanced Materials KR 인스턴싱된 머티리얼 - UE3 의 머티리얼 인스턴싱 시스템에 대한 개요입니다.
  • Material Instance Constant KR 머티리얼 인스턴스 불변 - 파라미터화된 머티리얼 인스턴스 사용 안내서입니다.

  • Material Examples KR 머티리얼 예제 - 다양한 종류의 머티리얼을 만드는 법에 대한 팁, 트릭, 테크닉입니다.
  • Material Basics KR 머티리얼 기본 - 기본 머티리얼에 대한 소개입니다.
  • Custom Lighting KR 커스텀 라이팅 - 커스텀 라이팅 모델 사용법입니다.
