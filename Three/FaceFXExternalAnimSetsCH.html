FaceFX外部动画集

  • FaceFX外部动画集
    • 概述
    • 创建外部动画集
    • 打开FaceFX Studio中的外部动画集
    • 添加动画至外部动画集中
    • 保存外部动画集

概述

FaceFX动画数据被存储为曲线名和关键帧。只要actor在Face Graph中拥有与动画曲线名称相匹配的节点，则角色可以播放那个动画。因此，动画可以被多个actor共享，并且在游戏中动态加载。被导出的动画集为研发人员提供了一个这样做的接口。这个文件介绍了如何在UE3中创建和使用外部动画集（External Animation Set）。它不会介绍在游戏中装载和卸载外部动画集（External Animation Set）的界面，而仅仅涉及在FaceFx Studio中创建和修改外部动画集（External Animation Set）的界面。

创建外部动画集

第一步是创建一个外部动画集（External Animation Set）： 右击一个现有的FaceFX Asset（FaceFX资源），然后选择“Create New FaceFX AnimSet...（创建新的FaceFX AnimSet...）”。

_OC3_Slade FaceFX资源可以在包\UTGame\Content\TestPackages\MatineeTest_Resources.upk中找到。_ 

在弹出的对话框中，输入Package（文件包）和Group（组）信息，并为外部动画集（External Animation Set）命名。点击OK按钮。要想查看新的动画集，你必须完全刷新内容浏览器(Ctrl+F5)。 

此时，外部动画集（External Animation Set）被添加到FaceFX Asset（FaceFX资源）上，供创建之用。尽管它可能与任何FaceFX Asset（FaceFX资源）相关联，但是外部动画集（External Animation Set）需要指定一个默认的FaceFX Asset（FaceFX资源），使其了解使用哪个角色模型。通过右击新创建的外部动画集（External Animation Set），并选择“Properties（属性）”，即可修改默认的FaceFX Asset（FaceFX资源）。

打开FaceFX Studio中的外部动画集

双击外部动画集（External Animation Set），或右击它，并选择“FaceFX Studio”来打开FaceFX Studio中的外部动画集（External Animation Set）。加载在外部动画集（External Animation Set）属性中存储的默认FaceFX Asset（FaceFX资源），然后将外部动画集（External Animation Set）安装到actor上。

注意在上述截图中的外部动画集（External Animation Set）显示为一种动画组。从用户角度看，已安装的外部动画集（External Animation Set）与动画组之间没有直观差异。然而本质上，动画组是被存储在FaceFX Asset（FaceFX资源）中，而外部动画集（External Animation Set）是被存储在Unreal文件包中的任何其他地方。

您每次仅可操作一个来自UnrealEd的外部动画集（External Animation Set）。然而在游戏中，您可以将多个外部动画集（External Animation Set）动态安装到一个FaceFX Asset（FaceFX资源）上。

添加动画至外部动画集中

起初，新创建的外部动画集（External Animation Set）将不含有任何动画。您可以将动画转移到外部动画集（External Animation Set）中，或者利用动画管理器生成新的动画。在FaceFX Studio中的actor菜单上选择“Animation Manager（动画管理器）...”。

通过动画管理器，从左侧的动画组下拉列表中选择外部动画集（External Animation Set）。在下列截图中点击带有两个向左箭头的按钮，即可将默认组中的Silence_Loop动画转移到外部动画集（External Animation Set）中。

点击“Create Animation（创建动画）...”按钮，并执行Create Animation Wizard（创建动画向导），即可通过声音提示来创建新的动画。确保外部动画集（External Animation Set）被选作Animation Manager（动画管理器）对话框左上侧的Primary Animation Group（首选动画组）。在下列截图中，通过分析在OC3_Slade文件包中存储的“welcome（欢迎）”声音提示，“welcome_external”动画已经添加到外部动画集（External Animation Set）中。

保存外部动画集

为了保存外部动画集（External Animation Set），仅需执行来自FaceFX Studio的保存操作。这将会把更改情况保存到FaceFX Asset（FaceFX资源）和外部动画集（External Animation Set）中。即使外部动画集（External Animation Set）呈现为FaceFX Asset（FaceFX资源）的组成部分，在保存时它将会被单独保存。保存将会把相对应的Unreal包标识为已修改，并且在提交你的修改之前你必须完全地保存Unreal包。
