概要

ヘルプ コマンドレットは実行可能なコマンドレット、コマンドレットの用途、およびコマンドレットのパラメータ要件を調べるために利用します。

オペレーション

このコマンドレットを実行するには、「コマンドプロンプトウィンドウ」から、 UnrealEngine3\Binaries ディレクトリをナビゲートします。

構文

構文は次の通りです: 

[GameName].exe help <list | commandletname | webhelp commandletname>

パラメータ

list - 有効なコマンドレットのリスト表示
commandlet name - 指定のコマンドレットに関するヘルプ情報の表示
webhelp - コマンドレットについて記述しているウェブページのURLからブラウザを起動

サンプル

どのコマンドレットが使用可能か知るには、下記を実行: 

game.exe help list

以下は、出力結果の一例です： 

Core.Help                                -コマンドレットに関するヘルプ情報の表示
Engine.SmokeTest                         - 一連のビルド検証テストの実行
Editor.CutDownContent                    - パッケージ内の未使用コンテンツを削除
Editor.Make                              - UnrealScriptパッケージのリビルド
Editor.PkgInfo                           - Unrealパッケージに関する情報表示
Editor.ScaleAudioVolume                  - 全パッケージのオーディオ データ量を計測
Editor.StripSource                       - コンパイル済みスクリプト パッケージからのソース コード削除

また、特定のコマンドレットに関するヘルプ情報を見るには、次のコマンドを実行します。 

game.exe help <commandlet name>

ヘルプ コマンドレットの表示結果は、次の通りです。 

名称:Core.Help
機能:コマンドレットに関するヘルプ情報を表示
用法:gamename.exe help <list | コマンドレット名 | webhelp コマンドレット名>
オプション:
list                 - 有効なコマンドレットのリスト表示
commandlet name      - 指定のコマンドレットに関するヘルプ情報の表示
webhelp              - コマンドレットについて記述しているウェブページのURLからブラウザを起動

コマンドレットに UDN の文書が用意されている場合は、次のコマンドによって、ウェブヘルプのオプションを使った参照が可能です。 

game.exe help webhelp help

上記のコマンドを実行すると、このページが表示されます。

他のコマンドレットでのヘルプ

ヘルプ情報を自分のコマンドレットに追加したい場合は、 コマンドレットの作成方法 をご覧ください。

コマンドレットリスト

コマンドレットの完全なリストについては、 コマンドレットリスト ページをご覧ください。
