인풋 / 아웃풋

언리얼 엔진 3 의 인풋과 아웃풋은 세 가지 다른 방법으로 이뤄집니다. 첫 번째 방법은 환경설정 파일을 사용하는 방법으로, 키 바인딩 시스템을 확장하는 것입니다. 둘째 방법은 정보를 읽고 쓰기 위해 TCP/IP 패킷을 사용하는 방법입니다. 셋째 방법은 언리얼 오브젝트 직렬화(serialization)와 역직렬화를 통하는 것입니다. 이 세 가지 시스템으로 세이브 게임을 만들거나, 웹 서버에서 뉴스를 읽거나, 프로파일 데이터를 웹서버에 전송하거나, 어딘가에 임의의 데이터를 저장하거나 할 수 있습니다.

테크니컬 토픽
  • Adding Editor Hotkeys KR - 언리얼 에디터에 새로운 핫키를 추가하는 법 안내서입니다.
  • Configuration Files KR - 언리얼 엔진 3 에서의 환경설정 파일 작동방식 입니다.
  • Directory Layout KR - 언리얼 엔진 3 에 대해 디렉토리 레이아웃 디자인 관련 안내서입니다.
  • Editor Hotkeys KR - 언리얼 에디터가 사용하는 핫키 안내서입니다.
  • Exec Functions KR - 언리얼 엔진 3 의 펑션 키 매핑 개요입니다.
  • Key Binds KR - 키 바인드를 새로 추가하는 법과, 언리얼 엔진 3 의 키 바인드 시스템이 작동되는 방식에 대한 개요입니다.
  • Tcp Link KR - 언리얼 엔진 3 안에서 TCP Link 를 사용하는 법 관련 정보입니다.
  • 로지텍 게이밍 G-키 SDK - 로지텍 게이밍 마우스와 키보드에 있는 G-키나 전용 마우스 버튼을 확인하는 기능을 언리얼 엔진에 쉽게 추가할 수 있습니다.
  • 로지텍 게이밍 LED SDK - 로지텍 게이밍 마우스와 키보드의 LED 라이트를 바꾸는 기능을 언리얼 엔진에 쉽게 추가할 수 있습니다.

콘텐츠 제작
  • Config Savegame System KR - 환경설정 시스템을 사용하여 세이브 게임 시스템 만드는 법입니다.
  • Web Server KR - 언리얼 엔진 3 에서의 웹 서버와 웹 어플리케이션 작동방식 입니다.

Gems
  • 게임 상태 저장하고 로드하기 - 유연한 게임 상태 저장 / 로드 시스템을 만드는 법입니다.
