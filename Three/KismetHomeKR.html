키즈멧 비주얼 스크립팅

레벨 내 게임플레이 이벤트 스크립트를 짜는 것은 플레이어에게 재미있고 역동적인 환경을 만드는데 있어 매우 중요한 부분입니다. 프로그래머가 레벨 디자이너의 생각을 구현해야만 한다면 그다지 효과적이지 못할 것입니다. 키즈멧 비주얼 스크립팅 시스템을 통해 단순한 것에서 극도로 복잡한 것까지 다양한 이벤트를 레벨 디자이너가 손수 만들 수 있습니다. 개념은 간단합니다. 디자이너가 게임 내 특정 이벤트가 발생하면 실행할 액션을 연결해 주기만 하면 되는 것이지요. 게임플레이 프로토타이핑이나 심지어 전체 게임타입에서부터 문처럼 단순한 이동 액터를 만드는 데까지, 유연하고 강력한 시스템인 것입니다.

레벨 제작 토픽
  • Kismet User Guide KR - 키즈멧 에디터 사용 안내서입니다.
  • Kismet Reference KR - 모든 키즈멧 액션, 컨디션, 이벤트, 변수 관련 완벽 참고서입니다.
  • Mobile Kismet Reference KR - 모바일 전용 키즈멧 노드를 자세히 다루는 참고서입니다.
  • Kismet Examples KR - 유용한 테크닉과 샘플 시퀸스 예제입니다.
  • Using InterpActors KR - 키즈멧을 사용하여 움직이는 액터, 소위 '무버'(mover)를 만드는 법입니다.
  • Crowd System KR - UE3 의 크라우드 시스템에 대한 개요입니다.
  • Kismet Visual Debugger KR - 키즈멧 비주얼 디버거 사용 안내서입니다.

튜토리얼 토픽
  • DevelopmentKitGems Canvas Kismet Nodes KR - HUD 위에 그릴 수 있는 Canvas 키즈멧 노드 만들기 입니다.
  • DevelopmentKitGems Concatenate Strings Kismet Node KR - 두 문자열을 합치는 Concatenate Strings 키즈멧 노드를 만드는 법입니다.
  • DevelopmentKitGems Controlling Post Process Effects KR - 포스트 프로세싱 이펙트를 제어하는 노드를 만드는 법입니다.
  • DevelopmentKitGems For Loop Kismet Node KR - 키즈멧에서 'for 루프' 노드를 만드는 법입니다.
  • DevelopmentKitGems Iterator Kismet Nodes KR - 레벨에 있는 액터를 검색할 수 있는 키즈멧 노드를 만드는 법입니다.
