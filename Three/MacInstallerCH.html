概述

该文档介绍了如何配备可以用于分配针对 Mac 平台封装的 UDK 游戏的拖拽式安装器。

需求

要配备这个安装器，您将需要安装 Disk Utility（磁盘实用程序） 应用程序（默认情况下安装在 /Applications/Utilities 中）以及 Apple 的 Developer Tools（开发者工具） 。您也需要创建一个安装器背景图片。

配备安装器

安装器是一个磁盘图片，打开这个图片的时候会显示一个带有游戏图标的窗口，并且会显示一个到位于背景图片顶部的 Application 文件夹的快捷方式，其中包含一个简单的消息，向用户介绍有关安装这个游戏的方法。

创建一个可以写入的磁盘图片

  1. 通过 /Applications/Utilities 打开 Disk Utility（磁盘实用程序） 并点击工具栏中的 New Image（新图片） 按钮。
  2. 它会打开一个其中包含这个新图片的属性的面板。输入名称，为您的游戏选择足够大的尺寸，然后从 Partitions（分区） 下拉框中选择 单独分区 - Apple 分区映射 。然后点击 Create（创建） 按钮。
  3. Disk Utility（磁盘实用程序） 现在将会创建并安装您的新磁盘图片。

背景图片

  1. 打开在 Finder（查找器） 中最新安装的文卷并在其中创建一个名为 Background 的文件夹。然后将您的背景图片复制到这个 Background 文件夹。
  2. 现在，确保在 Finder（查找器） 中选择了包含安装文卷的窗口，并且这个窗口使用的是图标视图，然后按下 Command + J 打开这个窗口的属性。
  3. 在这个窗口的 Background（背景） 部分，选择 Picture（图片） ，然后将您的背景图片拖到图片区域。主要窗口现在应该可以正确地显示您的背景图片。
  4. 要隐藏 Background 文件夹，您需要打开 Terminal（终端） 应用程序并使用下面的命令： 
       /Developer/Tools/SetFile -a V /Volumes/Your_Volume_Name/background
    在我们的实例中将会是： 
       /Developer/Tools/SetFile -a V /Volumes/UDKGame/background

游戏和应用程序图标

  1. 将您的游戏拖到您的安装器安装文卷。然后在 Finder（查找器） 中打开您的启动盘并创建一个 Applications 文件夹的别名：
    • 选择这个文件夹。
    • 从 File（文件） 菜单中选择 Make Alias（创建别名） 。它将会创建“Applications alias（应用程序别名）”文件。
  2. 将这个文件拖到安装器文卷并重新命名为“Applications（应用程序）”。
  3. 现在再次打开窗口的属性 (Command + J) 并在需要的时候调整 Icons Size（图标尺寸） ，调整图标的位置和窗口的大小使其与背景图片相符。

磁盘图片图标

  1. 要更改磁盘图片的图标，请在您的桌面上选择安装文卷图标然后按下 Command + I 打开信息窗口。对您的游戏图标进行相同的操作。
  2. 在最近打开的信息窗口中点击游戏的图标选择它并按下 Command + C 进行复制。
  3. 切换到文卷的信息窗口，在其中选择它的图标，然后按下 Command + V 粘贴。
  4. 安装文卷现在应该与游戏具有相同的图标。

转换磁盘图片

  1. 返回到 Disk Utility（磁盘实用程序） 中，卸载安装器的磁盘图片，然后在选择了磁盘图片后点击 Convert（转换） 按钮。确保您选择 Compressed Image Format（压缩的图片格式） ，然后点击 Save（保存） 。在您选择不为压缩图片使用不同的名称的情况下您可能需要确认替换以前的文件。
  2. 就这么简单。只要 Disk Utility（磁盘实用程序）完成转换后，您就会有一个合适的拖拽式安装器可供分配。
