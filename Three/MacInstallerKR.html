드래그 앤 드롭 인스톨러

개요

맥 플랫폼용으로 패키징된 UDK 게임 배포에 사용할 수 있는, 드래그 앤 드롭 인스톨러를 준비하는 법에 대한 설명서입니다.

요구사항

인스톨러를 준비하려면 (디폴트로 /Applications/Utilities 에 설치되는) Disk Utility 앱과 아울러 애픽의 Developer Tools 가 설치되어 있어야 합니다. 인스톨러 배경 이미지도 만드는 것이 좋을 것입니다.

인스톨러 준비하기

인스톨러는 디스크 이미지로, 열면 사용자에게 게임 설치 방법을 간단히 알려주는 메시지가 담긴 배경 이미지 위에 Applications 폴더 바로가기와 게임 아이콘이 있는 창이 표시됩니다.

쓰기가능 디스크 이미지 만들기

  1. /Applications/Utilities 에서 Disk Utility 앱을 열고 툴바에서 New Image 버튼을 누릅니다.
  2. 새로운 이미지 프로퍼티와 함께 창이 열립니다. 이름을 입력하고, 게임 크기를 넉넉하게 선택한 후, Partitions 드롭박스에서 Single partition - Apple Partition Map 를 선택합니다. 그리고 Create 버튼을 누릅니다.
  3. Disk Utility 가 새 디스크 이미지를 만들고 마운트(mount)합니다.

배경 이미지

  1. Finder 에서 새로이 마운트한 볼륨을 열고, 그 안에 Background 라는 폴더를 만듭니다. 그리고 배경 이미지를 이 Background 폴더에 복사합니다.
  2. 이제 창에서 Finder 에 마운트한 볼륨이 선택되어 있는지, 아이콘 뷰 모드인지 확인한 다음, Command + J 키를 눌러 창의 프로퍼티를 엽니다.
  3. 창의 Background 부분에서 Picture 를 선택하고, 배경 이미지를 이미지 영역에 끌어 놓습니다. 주요 창에 배경 그림이 올바르게 표시될 것입니다.
  4. Background 폴더를 숨기려면, Terminal 앱을 열고 다음 명령을 사용해야 합니다: 
       /Developer/Tools/SetFile -a V /Volumes/Your_Volume_Name/background
    우리의 경우에는: 
       /Developer/Tools/SetFile -a V /Volumes/UDKGame/background

게임과 어플리케이션 아이콘

  1. 게임을 인스톨러의 마운트한 볼륨에 끌어 놓습니다. 그런 다음 Finder 에서 스타트업 디스크를 열고 Applications 폴더로의 alias 를 만듭니다:
    • 폴더를 선택합니다.
    • File 메뉴에서 Make Alias 를 선택합니다. 그러면 Application alias 파일이 생깁니다.
  2. 이 파일을 인스톨러의 볼륨으로 끌어 놓고 "Applications" 로 이름을 바꿉니다.
  3. 이제 창의 프로퍼티를 한 번 더 열고 (Command + J), Icons Size 를 원하는 대로 조절한 다음, 배경 이미지에 맞도록 아이콘 위치와 창 크기를 조절합니다.

디스크 이미지 아이콘

  1. 디스크 이미지 아이콘을 바꾸기 위해서는, 데스크탑에서 마운트한 볼륨 아이콘을 선택하고 Command + I 키를 눌러 인포 창을 엽니다. 게임의 아이콘에도 같은 작업을 해 줍니다.
  2. 새로 열린 인포 창의 게임 아이콘을 클릭하여 선택하고 Command + C 를 눌러 복사합니다.
  3. 볼륨의 인포 창으로 전환하고, 거기서 아이콘을 선택한 다음 Command + V 를 눌러 붙여넣습니다.
  4. 마운트한 볼륨 아이콘이 게임과 같아질 것입니다.

디스크 이미지 변환하기

  1. Disk Utility 로 돌아와서, 인스톨러의 디스크 이미지 마운트를 해제(unmount)한 다음, 디스크 이미지를 선택한 상태로 Convert 버튼을 누릅니다. Compressed Image Format 을 선택했는지 확인한 다음 Save 를 누릅니다. 압축된 이미지에 다른 이름을 사용하도록 하지 않은 경우, 예전 파일을 대치하겠냐는 확인창이 뜹니다.
  2. 다 됐습니다. Disk Utility 의 변환 작업이 끝나면, 배포용 드래그 앤 드롭 인스톨러가 이쁘게 생깁니다.
