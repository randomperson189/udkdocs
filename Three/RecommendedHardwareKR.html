언리얼 개발용 컴퓨터 구매 안내

사용자용 최소 PC 요구 사항

  • Windows XP(DirectX 9.0c 포함)
  • 셰이더 모델 3.0을 지원하는 그래픽 카드.

개발자용 최소 PC 하드웨어 요구 사항

  • Windows XP(DirectX 9.0c 포함)
  • 2GHz 이상의 CPU
  • 2+ GB RAM
  • nVidia GeForce 7800와 같이 셰이더 모델 3.0을 지원하는 그래픽 카드

개발자용 권장 PC 하드웨어 사양

  • Windows 7 64비트 (DirectX 11 포함)
  • 2.4 GHz 이상의 듀얼 코어(또는 쿼드 코어) CPU
  • 2+ GB RAM
  • nVidia GeForce 7800처럼 셰이더 모델 3.0을 지원하는 PCI Express 그래픽 카드
  • 모니터 2 개(1600x1200 이상의 해상도)

참고: 네트워킹 코드 작업을 하는 경우, 듀얼 프로세서 구성이 매우 유용합니다. 서버와 클라이언트를 동일한 컴퓨터에서 만족스러운 속도로 실행할 수 있습니다.

그래픽 카드 드라이버

각 카드 제조사에서 공개한 최신 안정 버전을 사용하시길 추천합니다:

  • NVIDIA 드라이버 다운로드.
  • ATI 드라이버 다운로드.

64비트 퍼포먼스

에픽의 개발자들은 윈도우 7 64-비트를 주요 개발 OS 로 사용합니다. 가장 큰 장점은 4GB 이상의 RAM을 사용할 수 있어 끊임없이 디스크 스왑을 더 이상 하지 않아도 되기에 반복 시간이 크게 단축됩니다.

프로그래머에게 미치는 가장 명백한 혜택은 다음과 같은 경우에 나타납니다.

  • UnrealScript 컴파일
  • 편집기 실행. 1-2개의 게임의 복사본을 실행.
