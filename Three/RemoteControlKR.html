Remote Control(원격 제어) 기능

개요

Remote Control 은 렌더링 옵션 조작, 액터 조사, 실시간 통계 확인에 사용할 수 있는 신기능입니다.

Remote Control

2007년 4월 QA-승인 빌드 이전, 에디터 이외에서의 플레이 세션 도중에는 Remote Control 이 기본적으로 켜져 있었습니다.

주: 2007년 4월 QA-승인 빌드 이후 엔진은 게임 실행시 wxWidget 을 사용하지 않도록 변경되었는데, 에픽의 게임 발매시가 그러하기 때문입니다. 즉 더이상 Remote Control 창이나 editactor 기능이 지원되지 않는다는 뜻인데, 명령줄에 -remotecontrol 나 -wxwindows 를 넣어 예전처럼 사용할 수 있기는 합니다.

Rendering Page

Rendering Page(렌더링 페이지)에는 토글하거나 설정할 수 있는 여러가지 세팅과 통계 목록이 담겨 있습니다.

툴바에는 레벨을 열 수 있는 아이콘이 있습니다.

세팅

  • Game Resolution 게임 해상도 - 표준 해상도나 전체화면 모드 중 하나를 선택하거나, 임의의 해상도를 만들 수 있습니다.
  • Maximum Texture Size 최대 텍스처 크기 - 32x32 - 4096x4096 에서 선택합니다.
  • Maximum Shadow Size 최대 그림자 크기 - 32x32 - 512x512 에서 선택합니다.
  • Enable Post Process Effects 포스트 프로세스 이펙트 켜기 - 참이나 거짓 중 하나입니다.
  • View Mode 뷰 모드 - Wireframe 와이어프레임, BrushWireframe 브러시 와이어프레임, Unlit 라이팅제외, Lit 라이팅포함, LightingOnly 라이팅만, LightComplexity 라이팅 복잡도, ShaderComplexity 셰이더 복잡도 중 하나입니다.
  • Slomo 슬로우모션 - 값을 설정합니다. (정상은 1.0)
  • FOV 시야 - 값을 설정합니다. (보통 90.0)
  • Showflags 표시 플랙 - 다음에 대한 토글입니다. Bones 본, Bounds 바운드, BSP, Collision 충돌, Constraints 제약, Decals 데칼, Decal Info 데칼 인포, Fog 안개, Foliage 초목, Hit Proxies 히트 프록시, Level Coloration 레벨 채색, Mesh Edges 메시 에지, Missing Collision 빠진 콜리전, Particles 파티클, Vertex Colors 버텍스 컬러, Scene Capture Portals 씬 캡처 포털, Shadow Frustums 그림자 절두체, Skeletal Meshes 스켈레탈 메시, Skins 스킨, Sprites 스프라이트, Static Meshes 스태틱 메시, Terrain 터레인, Terrain Patches 터레인 패치
  • Dynamic Shadows 동적인 그림자 - 켜고 끄기 토글입니다.
  • Show HUD HUD 표시 - HUD 그리기 켜고 끄기 입니다. (UnrealUI scene 과는 다릅니다.)
  • Players Only 플레이어만 - 켜고 끄기 토글입니다.

통계

  • Frames Per Second 초당 프레임 - 켜고 끄기 토글입니다.
  • D3D Scene D3D 씬 - 지금은 사용되지 않습니다.
  • Memory 메모리 - 켜고 끄기 토글입니다.

Actors Page

Actors Page(액터 페이지)에는 현재 레벨의 모든 액터의 트리 목록에다 그 목록 필터링을 위한 제어기도 들어 있습니다.

툴바에 있는 아이콘은 다이내믹 액터 표시 토글, 액터 목록 새로고침, 선택된 액터 프로퍼티 표시, 서브-오브젝트를 디버그 옵션과 함께 표시, 액터 트리 자동-펼침, 조준선 아래 액터에 대한 프로퍼티 표시 등입니다.

액터에 대한 프로퍼티를 표시할 때 선택된 액터를 고정, 프로퍼티를 클립보드에 복사, (editinline Object 포함) 프로퍼티 전체를 클립보드에 복사, 모든 범주를 접고 펼치는 옵션이 있습니다.

주: PIE 세션을 실행중인 상태에서 액터를 레벨에 추가하면, PIE 전파 옵션을 켜둔 상태라 해도 해당 세션 도중 그 액터는 보이지 않습니다. PIE 세션을 다시 시작해야 새로 놓은 액터를 볼 수 있습니다.

Stats Page

Stats Page(통계 페이지)에는 개별적으로든 그룹으로든 토글시킨 통계 그룹을 트리 목록으로 볼 수 있습니다.

그룹

  • Physics 피직스 - 역학, 이벤트 등
  • Streaming 스트리밍 - 게임/렌더링 스레드, 오디오, 로딩 시간 등
  • Engine 엔진 - 포울리지, 터레인, 데칼, 인풋, HUD, 그림자 등
  • FaceFX FaceFX - 모핑, 머티리얼, 본 블렌딩 등
  • Game 게임 - 액터, 컴포넌트, 스크립트, 키즈멧, 가비지 콜렉션 등
  • UI UI - 씬, 위젯 등
  • Audio 오디오 - 컴포넌트, 인스턴스 등
  • Anim 애님 - 업데이트, 블렌드 등
  • Particles 파티클 - 스프라이트, 메시 등
  • BeamParticles 빔 파티클 - 스폰, 렌더 등
  • TrailParticles 트레일 파티클 - 스폰, 렌더 등
  • SceneUpdate 씬 업데이트 - 프리미티브, 라이트 등
  • Net 넷 - 패킷, 번치, 스태틱 오브젝트 리퍼런스, 네임 리퍼런스 등
  • CharacterLighting 캐릭터 라이팅 - 가시성, 환경 등
  • RHI RHI - 트라이앵글, 라인, 프리미티브
  • Octree 옥트리 - 점 및 반경 검사, 시간 및 수
  • SceneRendering 씬 렌더링 - 오클루전, 섀도우, 라이트 등
  • Collision 콜리전 - 레벨, 터레인, BSP, 스태틱 메시, 액터. 단일-선 및 다중-선 검사
  • DefaultStatGroup 디폴트 통계 그룹 - 루트
  • StatSystem 통계 시스템 - 프레임 캡처 당
  • Object 오브젝트 - 프로퍼티, 환경설정, 현지화, 네임 테이블 등
  • Memory 메모리 - 가상 메모리, 물리 메모리 등
  • Threading 스레딩 - 렌더/게임 스레드
  • AsyncIO 비동기 IO - 읽기 횟수와 크기 (성공, 취소, 현재)

콘솔 명령

Remote Control 을 토글하려면 REMOTECONTROL 또는 RC 콘솔 명령을 치면 됩니다.

주: 2007년 4월 QA-승인 빌드 이후로 이 콘솔 명령은 게임 실행파일에 -remotecontrol 나 -wxwindows 를 붙여 실행했을 때만 사용할 수 있습니다. 이 명령은 Play In Editor 세션에서 실행했을 때는 언제든지 사용할 수 있습니다.

명령줄에서 게임 실행파일을 불러올 때 Remote Control 을 억제시키려면, -norc 나 -noremotecontrol 를 붙여주면 됩니다.
