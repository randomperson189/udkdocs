리소스 디포

리소스 디포에는 여러가지 튜토리얼, 예제 코드, 다운로드와 아울러 다른 정보 소스 링크가 포함되어 있습니다.

  • UDK 젬
    실제 월드에 적용해 볼 수 있는 예제입니다. 스타터 키트 - 마우스 인터페이스 - 커스텀 키즈멧 노드 - 인테리어 매핑 - 왜곡된 리플렉션 - 다이내믹 내비메시 장애물 - 얼룩 그림자 - 모듈식 폰 - 컴포넌트 사용법 - 에지 디텍션 - 등등
  • 비디오 튜토리얼
    언리얼 엔진 3 와 UDK 에 관련해서 에픽과 3DBuzz 가 만든 비디오 튜토리얼 모음입니다. 스켈레탈 메시 파이프라인 - 에디터 인터페이스 - 레벨 디자인 - 키즈멧 - 마티네 - 머티리얼 - 등등
  • UDK 커뮤니티 링크
    UDK 관련 걸출한 커뮤니티가 개발한 문서와 튜토리얼 링크입니다. 문서 튜토리얼 - 비디오 튜토리얼 - 툴과 유틸리티
  • 다운로드
    언리얼 엔진 3 와 UDK 에서 내려받아 사용할 수 있는 애셋과 자료 모음입니다. FBX 캐릭터 예제 - 로고 - 예제 소스 코드.

추가 자료
  • Whizzle Creation Document KR 위즐 제작 문서 - 위즐(Whizzle) 제작과정을 담은, 소스 포함 문서입니다.
  • Dungeon Defense Developer Blog KR 던전 디펜스 개발 블로그 - 던전 디펜스(Dungeon Defense) 게임, 소스, 개발 블로그입니다.
  • Mod Home KR 모드 홈 - 언토3 나 기어즈 오브 워 를 사용하는 모드 개발자용 정보와 자료입니다.
