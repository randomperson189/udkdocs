스케일폼 GFx

문서 변경내역: Jason Bestimt 작성. Nick Whiting 업데이트. 홍성진 번역.

스케일폼(Scaleform) GFx 를 통해 어도비 플래시 프로페셔널(Adobe Flash Professional)로 만든 모션 그래픽을 언리얼 엔진 3 에서 유저 인터페이스와 HUD 로 사용할 수 있습니다. 화면에 직접 렌더링할 수도 있고, 텍스처에 렌더링하여 머티리얼 에서 사용해가지고 월드 안의 지오메트리에 적용시킬 수도 있습니다. 스케일폼 GFx 에는 게임 안에서 직접 사용할 수 있도록 디자인되고, 애니메이션같은 효과도 지원하는, 미리 제작된 위젯 모음집이 제공되므로, 아티스트가 직접 UI 를 제작할 수 있습니다.

이제 언리얼 엔진 3 에 스케일폼이 통합되어, 언리얼스크립트는 물론 키즈멧 비주얼 스크립트도 플래시의 스크립트 언어 액션스크립트(ActionScript)와 함께 사용할 수 있습니다. 이를 통해 언리얼 엔진 3 툴에 친숙한 개발자가 플래시의 모션 그래픽 기능을 활용하여 실감나고 역동적인 인터페이스를 만들 수 있습니다.

일반적인 스케일폼 GFx 작업방식에 대한 문서, 특히나 CLIK 컴포넌트에 관련해서는 오토데스크 공식 스케일폼 문서 사이트 를 참고하시기 바랍니다. (UDK 튜토리얼 11편 전편에 대해 한글 자막이 제공되어 있습니다.)

주: 나와있는 문서 대부분이 스케일폼 3.0 으로 만든 것이지만, 스케일폼 4.0 에도 적용 가능합니다.

  • Getting Started with CLIK CLIK 시작하기 (영문)
    1. 초기 셋업 - 새로운 CLIK(컴포넌트 경량 인터페이스 키트)를 사용하여 기본적인 프론트 엔드 메뉴 시스템을 빠르게 프로토타이핑하는 법을 안내하는 튜토리얼입니다. 메인 메뉴, 옵션 화면 등이 모두 버튼, 슬라이더, 옵션 스테퍼, 라디오 버튼과 같은 핵심 CLIK 컴포넌트로 구성됩니다.
    2. 메인 메뉴 셋업 - 메인 메뉴에 기본적인 함수성을 약간 추가해 봅니다.
    3. 옵션 화면 만들기 - 메인 메뉴에서 옵션 화면으로 이동하는 버튼을 만들고, 첫 옵션에 난이도 설정 옵션 스테퍼를 추가합니다.
    4. 체크박스, 라디오 버튼, 슬라이더 - 비디오 세팅 체크박스, 라디오 버튼, 볼륨 슬라이더 등 여러가지 컴포넌트를 추가합니다.
    5. 함수성 추가하기 - OK 와 취소 버튼은 물론, 난이도 세팅 옵션 스테퍼와 라디오 버튼에 약간의 함수성을 추가합니다.
    6. 변경 유지하기 - OK 버튼이 눌리면 사용자가 변경한 내용이 유지되도록 옵션 화면을 셋업합니다.
    7. 배경 추가하기 - 튜토리얼 1-6 에서 만든 메뉴 구성 요소들에 스킨을 입히는 방법입니다. 이 과정은 여덟 단계로 나뉘며, 이번 단계에서는 메뉴에 배경 그래픽을 추가합니다.
    8. 매경 임포트하기 - 어도비 포토샵에서 만든 그래픽을 임포트하여 옵션 화면의 창으로 씁니다. 컴포넌트를 정렬하여 창에 맞추기도, 컴포넌트를 복제하여 스킨을 다르게 입힌 버전을 만들기도 합니다.
    9. 메인 메뉴 버튼 스킨 입히기 - 메인 메뉴 버튼에 스킨을 입힙니다.
    10. OK 와 취소 버튼 스킨 입히기 - OK 와 취소 버튼에 스킨을 입힙니다.
    11. 사운드 슬라이더 스킨 입히기 - 사운드 슬라이더에 스킨을 입힙니다.
    12. 체크박스 스킨 입히기 - 비디오 세팅 체크박스에 스킨을 입힙니다.
    13. 라디오 버튼 스킨 입히기 - 비디오 세팅 라디오 버튼에 스킨을 입힙니다.
    14. 옵션 스테퍼 스킨 입히기 - 난이도 옵션 스테퍼에 스킨을 입힙니다.

스케일폼 GFx 통합

스케일폼 GFx 중 언리얼 엔진 3 에 통합된 부분은:

  • 3Di 렌더링 포함 GFx 런타임 플레이어 (현재 플래시 8이, 곧 플래시 10이 지원됩니다.)
  • CLIK 플래시 UI 프레임워크
  • 아시아 언어 채팅 지원용 스케일폼 IME
  • 성능 및 메모리용 AMP 프로파일러
  • 게임 UI 샘플 - HUD, 메뉴, 3D 인벤토리, 로딩 화면
  • 문서, 비디오, 데모

통합되지 않은 부분은:

  • Scaleform Video 는 UE3 / UDK 에 포함되지 않습니다. 추가 비용을 들여 플래시 콘텐츠에 비디오 솔루션을 통합시키려는 (소스 포함) UE3 라이선시께서는 스케일폼 세일즈 팀과 계약하여 Scaleform Video 를 추가할 수 있습니다. 주: Scaleform Video 를 통합하려면 소스 코드 접근 권한이 필요하기에 UDK 사용자는 사용하실 수 없습니다.
  • 콘텐츠 저작 도구. 어도비 플래시 호환 콘텐츠를 저작할 방법이 있어야 할 겁니다. 스케일폼은 어도비 크리에이티브 스위트의 일부로 포함된 어도비 플래시 툴셋으로 제작한 콘텐츠에 대해서는 공식적으로 지원합니다. Sothink SWF Quicker 같은 기타 둘을 사용해도 됩니다만, 스케일폼이 공식적으로 지원하지는 않습니다.

스케일폼 최신 업데이트는 스케일폼 웹사이트를 확인해 주시기 바랍니다. Scaleform(스케일폼), GFx 는 Scaleform Corporation 에 등록된 상호입니다. Scaleform GFx ⓒ 2011 Scaleform Corporation. 판권 소유.

Adobe(어도비)와 Flash(플래시)는 상호 또는 미국 및/또는 각국의 Adobe Systems Incorporated 에 등록된 상호입니다.

스케일폼 GFx 라이선스는 (상용이든 비상용이든) UE3 라이선시와 UDK 사용자에게 무료로 제공됩니다.

지원

UDK 유저에 대해서는 UDK 포럼이나 UDN 온라인 문서, 샘플, 비디오를 통해 스케일폼 및 UDK 지원을 하겠습니다.

상용 UDK 개발자용 스케일폼 프리미엄 지원도 있으며, 추가 비용을 통해 스케일폼으로부터 다음과 같은 지원을 받게 됩니다:

  • 스케일폼 개발자 사이트 접근 - 최신 스케일폼 문서, 샘플, 비디오
  • 스케일폼 수석 기술자들의 이메일 및 전화 직접 지원
  • 스케일폼 수석 기술자 및 기타 상용 게임 개발자들과 주선하는 사설 포럼

대부분의 UDK 개발자들에게 프리미엄 지원이 필요하지는 않을 것이나, 스케일폼 개발자 사이트나 기술 지원 문의를 직접 하시기 전에 참고삼으시라 말씀드렸습니다. 스케일폼 프리미엄 지원에 대한 문의는, 이메일 sales@scaleform.com 을 통해 부탁드립니다.

UDK 예제 UI 파일

CLIK 버튼과 라벨을 사용한 기본 씬

\UnrealEngine3\UDKGame\Flash\example\udk_GFxCLIKBasicScene.fla 참고.

이 문서 위의 예제를 통해 생성된 파일입니다. CLIK 버튼 둘이 들어 있으며, 버튼 클릭을 통해 단일 라벨의 문구를 구동합니다. 버튼이 클릭/눌렸을 때 함수가 실행되도록 설정하는 예제입니다.

콘트롤러 버튼 입력 샘플

\UnrealEngine3\UDKGame\Flash\example\udk_GFxControllerButtonInput_Sample.fla 참고.

이 파일은 handleInput의 사용법, 콘트롤러 버튼이 눌렸을 때 함수 구동 및 UI 내부의 액션 설정법을 다룹니다. XBOX 360 콘트롤러 버튼 그래픽이 (UI 내부의 버튼바에 있는 버튼과 비슷한) 실제 선택가능 버튼이 아닌 상태에서 이게 제대로 작동하기 위해선, 투명 CLIK 버튼을 추가하여 초점을 줘야 합니다. 콘트롤러 버튼 눌림 호출명은:

  • GAMEPAD_A
  • GAMEPAD_B
  • GAMEPAD_X
  • GAMEPAD_Y
  • GAMEPAD_R1
  • GAMEPAD_R2
  • GAMEPAD_R3
  • GAMEPAD_L1
  • GAMEPAD_L2
  • GAMEPAD_L3
  • GAMEPAD_START
  • GAMEPAD_BACK

SWF 를 미리보려면, 어도비 플래시 플레이어가 아닌 GFx 플레이어에서 봐야 합니다. .fla 안에 ActionScript 각 부분이 세부 기능 설명과 함께 기술되어 있습니다.
