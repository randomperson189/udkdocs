Movie / Scene / Stage

Movie
무비 - 플래시 무비란 흔히 플래시로 만든 콘텐츠를 말합니다. 플래시 콘텐츠를 총체적으로 담는 것, 예를 들면 어도비 플래시 프로페셔널에서 만든 .fla 파일을 말합니다.

Scene
씬 - 씬이란 무비의 "클립", 단편을 말합니다. 플래시 무비에는 각각 자체 독립적인 씬이 여럿 있을 수 있습니다. 하나의 무비 안에 있는 여러개의 씬은, stop() 호출과 같은 외부 개입 없이 연속 재생됩니다.

Stage
스테이지 - 스테이지는 퍼블리싱한 플래시 무비에 보이는 부분입니다. 요소의 배치와 조작이 일어나는 플래시 내 작업 공간을 정의합니다.

SWF (스위프)

SWF 는 퍼블리싱된 플래시 무비의 표준 파일 포맷입니다. 스케일폼(은 물론 플래시 플레이어의 웹 콘텐츠)에서는 물론이고 언리얼로도 임포트되는 포맷입니다. 플래시의 무비를 구성하는 모든 이미지, 벡터 그래픽, ActionScript 전부가 포함됩니다.

Symbol

플래시에서 심볼 이란 단지 재사용 가능한 오브젝트입니다. 그래픽이나 버튼, 무비클립 등이 해당됩니다. 심볼은 같은 도큐멘트에서든 다른 도큐멘트에서든 여러번 재사용 가능합니다. 어느 한 심볼의 사본이 사용되는 경우를 인스턴스 라고 합니다.

MovieClip
무비클립 - 무비클립 심볼은 재사용 가능한 플래시 애니메이션 조각입니다. 본질적으로는 다른 플래시 무비 안에서 사용할 수 있는 자체 독립적 플래시 무비입니다. 여기에는 그래픽, 셰이프, ActionScript 등이 포함됩니다.

Graphic
그래픽 - 많이 들어보셨을 법한 그래픽 심볼은 말 그대로 비트맵 그래픽을 나타냅니다.

Button
버튼 - 버튼 심볼은 클릭, 키 입력 등의 상호작용에 반응하여 그에 따라 일정한 동작을 하는 오브젝트를 나타냅니다.

Instance Name

무비에서 사용되는 심볼의 인스턴스에는 InstanceName 이라는 프로퍼티가 있습니다. WidgetInitialized (위젯 초기화) 호출로 ActionScript 나 UnrealScript 를 통해 인스턴스를 접근하고 제어하는 데 사용되는 식별자입니다.

ActionScript

ActionScript(액션스크립트) 는 플래시 무비와 그 안의 요소를 프로그래밍적으로 제어하기 위해 플래시에서 사용되는 스크립팅 언어입니다.

Tween

트윈 은 두 값 사이(between 의 TWEEN)를 보간하는 애니메이션입니다. 'ease' in / out 처럼 일정 부분 조절은 가능한 부드러운 애니메이션을 말합니다.

CLIK 컴포넌트

CLIK (Common Language Interface Kit, 공용 언어 인터페이스 키트) 컴포넌트는 UI 제작에 요긴하고 자신에 맞게 고쳐쓰기도 쉬운 내장 함수를 제공하는 UI 컴포넌트 집합입니다.

Bagging

배깅 이란 추상화 레이어 효과를 내기 위해 한 클립 안에 다른 클립을 겹치는 것을 말합니다. 시간선상에 애니메이팅되고 있는 클립의 코드를 통해 특정 프로퍼티를 변경하거나 하면 해당 클립의 시간선이 완전히 깨져버립니다. 코드로는 계속 겹친 클립을 수정하도록 하면서 추가 레이어를 애니메이트시키는 방법으로 이 문제를 해결할 수 있습니다.
