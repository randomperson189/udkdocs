Scaleform GFx Launcher

Scaleform GFx Launcher 는 플래시 표준 플레이어보다 실제 게임에서 보이는 것에 가까운 환경에서 플래시 무비를 미리볼 수 있도록 하기 위해 스케일폼이 제공하는 툴입니다.

Scaleform GFx Launcher 설치

언리얼 엔진 3 개발용 Scaleform GFx Launcher 의 표준적인 설치 과정은 다음과 같습니다:

  1. Adobe Flash Professional 에서 Help > Manage Extensions 로 가서 Adobe Extension Manager 를 실행시킵니다.
  2. Launcher 의 우상단에 있는 Install 버튼을 누릅니다.
  3. 열리는 파일 브라우저에서 [UE3Directory]\Binaries\GFx\CLIK Tools 디렉토리로 이동하여 Scaleform CLIK.mxp 파일을 선택합니다.
  4. 열리는 라이선스 대화창에 동의를 해 주셔야 합니다.
  5. 설치에 성공했다는 대와창이 나타납니다.
  6. 이제 Adobe Extension Manager 대화창에 Scaleform GFx Launcher 가 표시됩니다.
  7. Adobe Flash Professional CS4 를 재시작, Extension Manager 를 닫습니다.
  8. Window > Other Panels 로 가서 Scaleform Launcher 를 선택합니다.
  9. Scaleform Launcher 패널이 열립니다.

Scaleform GFx Launcher 셋업

Scaleform Launcher 는 GFx player 를 가리키도록 설정해 줘야 CLIK 위젯과 그 함수성을 Adobe Flash Professional 안에서 미리볼 수 있씁니다.

  1. 버튼을 클릭하여 Profile 을 새로 추가합니다.
  2. GFx player 를 리퍼런스시켜줘야 합니다. 버튼을 울러 플레이어를 추가합니다.
  3. [UE3Directory]\Binaries\GFx 로 이동합니다.
  4. FxMediaPlayer.exe 를 선택합니다. 주: 스크립트가 느리게 돌아간다는 경고창이 뜨면 NO 를 선택하십시오. 이미 알려져 있는 문제로, 곧 스케일폼에서 고칠 것입니다.
  5. 플레이어 이름을 FxMediaPlayer 로 합니다.
  6. Profile Name 필드에 프로파일 이름을 지으면 됩니다.

주: 디폴트 Adobe Flash Professional 렌더러도 그대로 남아 있어, GFxPlayer 에서 SWF 파일을 미리볼 수 있습니다. Scaleform Launcher 패널의 커다란 "Test with ..." 버튼을 눌러줘야 합니다.

원한다면 FxMediaPlayerNoDebug.exe 플레이어를 사용하는 다른 프로파일을 만들 수도 있습니다. 이 플레이어는 콘솔 안에서의 인스턴스 로딩을 보고하지 않으며, ActionScript 안에서만 추적 명령을 뱉어냅니다.

분할 화면 미리보기용 추가 프로파일 구성

표준 화면과 분할 화면 해상도에 대한 UI 위치와 스케일을 정확히 테스트하기 위해서, 이전 단계에 따라 복수의 프로파일을 구성하여 GFxPlayer 미리보기 창이 특정 해상도에서 시작되도록 할 수 있습니다.

  1. 플레이어 구성을 마치고 나면, Scaleform Launcher 패널에서 버튼을 클릭합니다.
  2. 프로파일 이름을 SD 로 합니다.
  3. 명령 파라미터 텍스트 필드에서 %SWF PATH% 뒤에 -res 960:720 를 붙입니다.
  4. OK 를 눌러 저장합니다.
  5. 주 Launch 를 누르면 무비가 뷰포트에 맞도록 스케일 조절됩니다. 플레이어에 가득 차게 하려면 키보드의 Ctrl+D 키를 누르십시오.

CLIK 라이브러리 설치

ActionScript 2 / Scaleform 3

  1. Adobe Flash Professional CS4 에서 Edit > Preferences 로 갑니다.
  2. ActionScript 를 선택합니다.
  3. 버튼을 클릭합니다.
  4. 버튼으로 새 항목을 추가합니다.
  5. 경로를 CLIK 디렉토리로 설정합니다. (예: [UE3Directory]\Development\Flash\AS2\CLIK)
  6. 추가한 경로가 위에서 두 번째에 오도록 합니다! (아래 그림 참고)

ActionScript 3 / Scaleform 4

  1. Adobe Flash Professional CS5.5 안에서 Edit > Preferences 로 갑니다.
  2. ActionScript 를 선택합니다.
  3. 버튼을 클릭합니다.
  4. 버튼으로 Source path 부분에 새 항목을 추가합니다.
  5. 경로를 CLIK 디렉토리로 설정합니다. (예: [UE3Directory]\Development\Flash\AS3\CLIK) - 아래 참고.
