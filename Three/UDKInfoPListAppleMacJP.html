Mac 用 Info.plist のカスタマイズ

  • Mac 用 Info.plist のカスタマイズ
    • 概要
    • バンドル名 (CFBundleName)
    • バンドル識別子 (CFBundleIdentifier)
    • 高度な変更

概要

Info.plist は、アプリケーションパッケージに組み込まれ、アプリケーションに関係するさまざまなことがらを制御します。Finder に示される表示名は、ここにリストされます。また、アプリケーションを一意に識別するバンドル識別子もここにリストされます。

詳細については、 Apple's documentation on Info.plist (Info.plist に関する Apple のドキュメンテーション) のページを参照してください。

バンドル名 (CFBundleName)

バンドル名 (CFBundleName) とは、まさにバンドルのための名前であり、実行ファイルの名前としても使用されます。Finder 内でアプリケーションのアイコンの下やアプリケーションのメニューバーで表示されるため、長すぎてはいけません。16 文字を超えないようにするのがよいでしょう。また、スラッシュ ( / ) および ( : ) を含めることができません。

バンドル識別子 (CFBundleIdentifier)

CFBundleIdentifier はアプリケーション バンドルを識別します。これに含めることができる文字は、英数字 (A-Z、a-z、0-9) とハイフン (-)、ピリオド (.) だけです。

UDK アプリケーションを Mac App Store に提出する場合は、ここで入力するものが、App ID を作成したときに Developer Certificate Utility (開発用証明書ユーティリティ) で設定した識別子と一致する必要があります。

高度な変更

キーを変更する必要がある場合や、ダイアログボックスによって表示されないキーを Info.plist に追加する必要がある場合は、オーバーライドファイルを手動で編集することができます。このファイルは、UTF-8 でエンコードされた XML ドキュメントです。このファイル内にある、あらゆるキーは既存の設定項目をオーバーライドします。したがって、修正の必要性とそのリスクについて理解していない限りはキーを追加してはなりません。
