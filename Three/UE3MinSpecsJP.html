UE3 最低限スペックと推奨スペック

本書の概要: UnrealEngine? 3 を実行するコンピュータのハードウェアに最低限必要な、また推奨された仕様の提供。 - エンド ユーザーとデベロッパー両方用。

  • UE3 最低限スペックと推奨スペック
    • ユーザー用のPC 必要最低動作環境
    • 開発者用のPC ハードウェア必要最低動作環境
    • 開発者用の推奨PC ハードウェア仕様
    • Epic Games に使用される PC ハードウェア スペック
      • Epic のプログラマのハードウェア スペック
      • Epic のレベル デザイナーのハードウェア スペック
      • Swarm サーバ ファームのハードウェア スペック
    • グラフィックス カード ドライバー
    • パフォーマンス ノート
    • 64 ビット パフォーマンス

ユーザー用のPC 必要最低動作環境

  • Windows XP SP2
  • 2.0 GHz 以上のプロセッサ
  • 2 GB のシステム RAM
  • Shader Model 3.0 のサポートされたグラフィック カード

開発者用のPC ハードウェア必要最低動作環境

  • Windows XP SP2 と DirectX 9.0c
  • 2 GHz 以上の CPU
  • 2 GB 以上の RAM
  • nVidia GeForce 7800 などの Shader Model 3.0 をサポートしたグラフィック カード

備考: Vista 64 が、現在のメインストリームな開発環境ですが、Windows 7 64 ビットへもうすぐ移行します。

開発者用の推奨PC ハードウェア仕様

  • Windows Vista 64 ビット SP2、または Windows 7 64 ビット
  • 2.0 GHz 以上のマルチコア プロセッサ
  • 8 GB のシステム RAM
  • NVIDIA 8000 シリーズか、それ以上のグラフィック カード
  • 大量のハード ディスク ドライブ空き容量

Epic Games に使用される PC ハードウェア スペック

Epic のプログラマのハードウェア スペック

  • Lenovo ThinkStation D20 (Model 4158-C95)
  • Windows Vista 64 ビット SP2、または Windows 7 64 ビット
  • Dual Quad-Core Xeon Nehalem Processors (3.17GHz)
  • 24 GB DDR3 RAM
  • nVidia GeForce GTX 285 (1 GB DDR3)
  • 500 GB ハードドライブ 3 つ (1 つは OS ドライブ、2 つは RAID 0 設定のデータドライブ)

Epic のレベル デザイナーのハードウェア スペック

  • Dell Precision Workstation T7400
  • Windows Vista 64 ビット SP2、または Windows 7 64 ビット
  • Dual Quad-Core Xeon Processors (3.0GHz)
  • 16 GB DDR2 RAM
  • nVidia GeForce GTX 285 (1 GB DDR3)
  • 500 GB ハードドライブ 3 つ (1 つは OS ドライブ、2 つは RAID 0 設定のデータドライブ)

Swarm サーバ ファームのハードウェア スペック

  • IBM BladeCenter HS22 [7870AC1] (14 Nodes)
  • 1 つのノードのスペック:
    • Dual Quad Core Xeon Processors (2.53 GHz)
    • 24 GB DDR3 RAM
    • 73 GB SAS ドライブ

グラフィックス カード ドライバー

NVIDIA カードについては、現在、弊社では 公式にリリースされている ForceWare 191.07 ドライバーの使用を推奨しています。ここでダウンロードしてください。

ATI については、現在、弊社では 公式にリリースされている Catalyst 9.8 カタリストドライバーの使用を推奨しています。

パフォーマンス ノート

  • VTuneJP は、パフォーマンスの問題を探すのに非常に便利なツールですが Intel の CPU でしか動作しません。
  • NextGen Game アセットの行き詰まりを手助けするために、以下を行います。
    1. すべてのマシンは 16 GB 以上の RAM を持っています。
    2. すべてのマシンは、ゲームが位置する RAID 0 (Striped) ドライブを持っています。
    3. 夜間全員のマシンで実行される全社内のデフラグ プロセスがあります: RaxCo による Perfect Disk 8.0。
      • リモート マシン上のインストール、スケジュール実行、アップグレードなどを行う簡単な集中的管理
      • XP、Vista64 をサポート

原則としては、ボトルネックは I/O なので、RAID 0 や多くの RAM を得ることでかなり軽減されます。

64 ビット パフォーマンス

Epic では、ほとんどの人が Windows Vista 64 ビットを主要な開発 OS としています。もっとも大きな利点は、4GB 以上の RAM を持つことです。これは、常にディスクに切り替えすることがないので、イテレーション時間を大幅にスピードアップします。

プログラマに関しては、もっとも明白な利点は以下の通りです。

  • C++ のコンパイル、C++ のリンク
  • UnrealScript のコンパイル
  • エディタの実行、1 つから 2 つのゲームの実行

また、Vista には ReadyBoost があり、これは Outlook 2007 を改善するようです。
