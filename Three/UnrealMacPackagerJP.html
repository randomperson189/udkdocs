概要

MacPackager ツールとは、Mac 上で動作する「Unreal Engine 3」アプリケーションをパッケージ化するために使用されるものです。このツールは、署名証明書の設定およびインストール、ならびに、Mac App Store のためのアプリケーションへの署名も行います。

コマンドライン インターフェース

このツールは、引数をつけずにコマンドラインから起動することによって、グラフィカルなアプリケーションとして起動するか、あるいは、次のような形式で引数をつけて起動することができます。 

MacPackager Command GameName Configuration [ Languages ]

各項の意味は次のようになります。

Command (コマンド)
このツールの主モードです。各種モードの説明については、 コマンド? のセクションを参照してください。
GameName (ゲーム名)
パッケージされるゲームのためのディレクトリ名です。(例 : UDKGame )
Configuration (設定)
パッケージされるゲームのビルド設定です。(例 : Debug (デバッグ)、 Release (リリース)、 Shipping (出荷))。
[ Languages ] (言語)
+ で区切られたオプションの使用言語リストです。デフォルトの値は INT です。

コマンド

packageapp
解凍 (アンジップ) して Mac 上で稼働できるアプリケーションバンドルを、作成およびパッケージ化します。
packagemas
Mac App Store に提出できるアプリケーションバンドルを、作成およびパッケージ化します。
deploy
アプリケーションバンドルをともなった作成済み zip ファイルを、選択されている目的のフォルダにデプロイ (配備) します。zip の名前は、 GameName と Configuration に基づいて自動的に選択されます。
gui
Unreal Mac Configuration Wizard (「Unreal」Mac 設定ウィザード) を起動します。ウィザードは、[ Basic Settings ](基本設定) のタブが選択された状態で立ち上がります。 Basic Settings (基本設定) のセクションを参照してください。
guimas
Unreal Mac Configuration Wizard を呼び出します。このとき、[ Mac App Store ] タブが選択されています。 Mac App Store の設定 のセクションを参照してください。

Unreal Mac Configuration Wizard

Unreal Mac Configuration Wizard (「Unreal」Mac設定ウィザード) は、MacPackager ツールのためのグラフィカルなインターフェースです。このウィザードを使用すると、MacPackager のあらゆる設定項目にアクセスすることができます。たとえば、Info.plist の内容や、デプロイの目的フォルダ、ゲームのアイコンといった設定項目にアクセスできます。また、Mac App Store の証明書をインストールすることもできます。この証明書は、アプリケーションに署名するために使用するものです。

Unreal Mac Configuration Wizard へのアクセス

Unreal Mac Configuration Wizard は、 「Unreal Frontend」 から直接起動することができます。それには、[Settings…] (設定) ボタンをクリックします。

このボタンをクリックすると設定ツールが開くので、Mac 用アプリケーションを初期設定するか、開発中に必要となる場合には更新することができます。

Configuration Wizard インターフェース

Unreal Mac Configuration Wizard インターフェースは、2 つのタブから構成されています。1 つは、 Basic Settings タブで、常に表示されています。もう 1 つは、 Mac App Store Settings タブで、この Configuration Wizard が Mac App Store モードで稼働している場合にのみ利用することができます。どちらのタブにも、デプロイの各種局面に特化された機能が含まれています。

このインターフェースには、常に使用可能なボタンが 2 つ含まれています。

ボタン 説明
Configuration Wizard を終了します。パッケージ化プロセスが進行中であっても継続することはありません。
Configuration Wizard を終了します。パッケージ化プロセスが進行中であれば継続します。

コンフィギュレーション ウィザードのタブについては以下で詳しく説明します。

Basic Settings (基本設定)

[ Basic Settings ] タブを使用すると、開発および Mac プラットフォーム上でのテストのために、ゲームを設定することができます。

入力フィールド 説明
Bundle Name (バンドル名) この名前は、Finder においてアプリケーションのアイコンの下に表示されるとともに、アプリケーションのメニューバーでも表示されます。(例 : UDK Game)
Bundle Identifier (バンドル識別子) アプリケーションバンドルのための識別子です。Mac App Store のためにパッケージ化する場合は、Apple のデベロッパ ウェブサイトで先に作成した App ID のバンドル識別子と一致しなければなりません。(例 : com.EpicGames.UDKGame)
Destination path for deployment (デプロイのための目的パス) 作成されたアプリケーションアーカイブがデプロイ時にコピーされるパスです。
Icon (アイコン) アプリケーションのために使用されるアイコンが入っている ICNS ファイルのパスです。空の場合は、デフォルトである UDK のアイコンが使用されます。

Mac App Store の設定

Mac App Store Settings タブには、サードパーティ Mac デベロッパ アプリケーション証明書をインポートするためのツールが含まれています。なお、この証明書は、Mac App Store のためにアプリケーションを署名するために必要となるものです。

ボタン 説明
Apple のデベロッパ ウェブサイトから以前にダウンロードされた開発用証明書をインポートします。あるいは、キーチェーン アクセスからエクスポートされた .p12 ファイルをインポートします。
