UnrealScript 에 Visual Assist X 사용하기

문서 변경내역: Jeff Wilson 작성. 홍성진 번역.
  • UnrealScript 에 Visual Assist X 사용하기
    • 개요
    • 버전 및 설치
    • UnrealScript 지원 켜기
    • UnrealScript 스니펫 셋업

개요

Visual Studio 를 사용하는 프로그래머의 리팩터링, 인텔리센스 등의 기능을 강화시켜 주는 애드온 Visual Assist X 가 이제 UnrealScript 를 지원합니다. 이제 Visual Studio 에서 지원되지 않는 비공식 UnrealScript 기능 강화를 위해 Visual Assist X 변경이 가능합니다.

버전 및 설치

UnrealScript 가 지원되도록 하려면 최신 버전의 Visual Assist X 가 필요합니다:

  • Visual Assist X - Build 1862 빌드 노트

Build 1862.1 이 링크를 클릭하여 인스톨러를 내려받습니다. 모든 IDE 에 대한 통합 인스톨러입니다. 내려받기가 완료되면 인스톨러를 실행시킵니다.

파일 처리기(handler) 등록 방법

vs2010 이전 IDE 용 VA 를 설치할 때 VA 가 자동으로 .uc 파일에 대한 처리기를 등록합니다. VS2010 을 설치할 때 이루어 지는 작업이 아니니, 그 경우엔 수동으로 해 줘야 합니다..

  1. Tools 메뉴에서 Options 를 눌러 Visual Studio Options 대화창을 띄웁니다.
  2. Text Editor 부분을 펼친 다음 File Extension 을 선택합니다. 여기서 파일 확장자에 대한 새로운 처리기를 추가하면 됩니다.
  3. Extension 필드에 uc 를 추가한 다음 Editor 로 Microsoft Visual C++ 를 선택합니다. 그런 다음 버튼을 눌러 uc 확장자에 대한 처리기를 추가합니다.
  4. uci 파일 확장자에 대해서도 위의 과정을 반복합니다.
  5. 버튼을 눌러 변경사항을 저장합니다.

UnrealScript 지원 켜기

UnrealScript 지원은 기본적으로 꺼져 있습니다. 현재는 레지스트리를 수정하여 수동으로 켜 줘야 합니다.

UC 지원을 켜려면

  1. 아래 텍스트를 복사하여 .reg 확장자를 갖는 텍스트 파일로 저장합니다:
    • Visual Studio 2010 
      Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Whole Tomato\Visual Assist X\VANet10]
"EnableUC"=hex:01
    • Visual Studio 2008 
      Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Whole Tomato\Visual Assist X\VANet9]
"EnableUC"=hex:01
  2. 새로 생긴 레지스트리 파일을 더블클릭하거나 우클릭하고 맥락 메뉴에서 *병합(Merge)*을 눌러 실행시킵니다.
  3. UAC 가 파일을 실행시킬지 물어옵니다. 창이 뜨면 버튼을 누릅니다.
  4. 레지스트리가 수정된다는 경고창이 뜹니다. 버튼을 눌러 계속합니다.

UnrealScript 스니펫 셋업

이제 UnrealScript 용 VA 스니펫은 C/C++ 스니펫과 별개로 돌아갑니다. UnrealScript 스니펫이 C/C++ 스니펫과 섞여 있는 경우, UnrealScript 스니펫용으로 명확히 지정된 별도의 파일에 넣어줘야 합니다.

UnrealScript 스니펫 이동 방법

  1. C:\Users\\AppData\Roaming\VisualAssist\Autotext\cpp.tpl 을 C:\Users\\AppData\Roaming\VisualAssist\Autotext\uc.tpl 로 복사합니다.
  2. uc.tpl 파일이 생성되면 VA Snippet 에디터에 UnrealScript 가 노드로 나타납니다.
  3. C++ 노드에서 UnrealScript 스니펫을, UnrealScript 노드에서 C++ 스니펫을 제거합니다.
