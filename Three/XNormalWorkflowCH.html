使用XNormal的法线贴图工作流程

  • 使用XNormal的法线贴图工作流程
    • 概述
    • 工作流程
    • 结果

概述

本工作流程使用XNormal来烘焙法线贴图，使得光照的质量比之前的流程要高得多。 过去使用的法线贴图工作流程仍可使用，但如果您先想要更高质量的阴影，本文的工作流程是目前最好的。 它同时可以让您使用更少的支撑几何体，因为您不必再去解决不正确的阴影的问题。

工作流程

  1. 首先要确保您的模型包含1组平滑组。 使用编辑器来三角化您的模型也是有用的技巧，那样的话您不用担心任何程序会改变您的三角形。
  2. 如需将低多边形模型导出到xnormal，请使用这些设置：

    重点是平滑组以及切线和副法线
  3. 当载入您的低多边形模型到Xnormal时，确保 Use exported normals 为打开。
  4. 在烘焙法线贴图后，和以前一样使用同样的FBX设置来导出您的低多边形模型。
  5. 将您的模型导入虚幻时，选中 Import Tangents 和 Explicit Normals

结果
