Movement

マウスの動きには２つの「モード」があります。

Movement 使用法

自由な動きは、次の場合に使用されます。

  • カメラを移動する
  • 正射投影法のビューでアクタを移動する
  • フェイス ドラッグ
  • 頂点ドラッグ

軸のMovement は、次の場合に使用されます。

  • 非正射投影法のビューでアクタを移動する
  • ブラシを拡大縮小する
  • ブラシをスナップする

軸の回転は、次の場合に使用されます。

UnrealEd のバグ (上記の文書を作成中に発見されたもの）

Nが、 New(新規）と Intersect（交差）の両方に割り当てられています。

Sが、 Select all surfaces （すべてのサーフェスを選択）と select adj. slants（隣接スラントを選択）の両方に割り当てられています。

Select None （何も選択しない）が、 Z となっていますが、 N の誤りです。

Select Adj. Slanted（隣接スラントを選択）は、 S ではなく、 Y にする必要があります。

Intersect （交差）は、 N ではなく、 I です。

Save As （名前を付けて保存）は、 E としてメニューにリストする必要があります。
