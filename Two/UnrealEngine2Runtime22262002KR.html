개요

이 문서에서는 UnrealEngine2 Runtime 소프트웨어의 2226.20.02 다운로드 버전, 관련 문서, 릴리스 노트 및 정정에 대한 링크를 제공합니다.

서론

UnrealEngine2 Runtime 소프트웨어는 최첨단 교차 플랫폼, 데스크탑용 3D 렌더링 솔루션입니다. 최신 하드웨어 가속 3D 를 이용하는 이 런타임은 대화식의 검토 및 시뮬레이션을 위한 안정적이고 강력한 플랫폼을 제공합니다.

주: Unreal Engine 2 Runtime 은 아래에서 소개하는 이용가능 문서 및 추천 지원 채널 외의 다른 방법으로는 지원되지 않습니다.

  • 비공식 토론 및 지원에 대해서는 http://forums.beyondunreal.com/forumdisplay.php?f=438 에서 UnrealEngine2 Runtim 에 대한 BeyondUnreal 포럼을 확인해 보십시오.
  • Unreal Engine Runtime 의 상업적 사용권 부여가 가능합니다. 사용권의 조건에 관한 정보는 http://www.unrealtechnology.com 에 자세히 안내되어 있습니다.
  • 런타임 특정의 지원 문서 목차는 RuntimeTopicsKR? 를 참고하십시오.
  • UnrealEngine2 Runtime 의 시연 버전은 비상업적 및 교육적 목적에 한해서 사용권이 부여됩니다. 배포를 위한 게임 개발은 허용되지 않습니다. 다운로드에 앞서 사용권 협약을 신중히 읽고 이해하시기 바랍니다: UnrealEngine2RuntimeEULAKR?.
  • 기술적인 특징 및 기능에 대한 것은 저희의 UnrealEngine2Features? 문서를 참고하십시오.

시스템 요구 사양

런타임의 클라이언트/서버 기능에 상관없이, UnrealEngine2 Editor 와 UnrealScript 게임플레이 스크립팅 언어 컴파일러를 포함하는 콘텐츠 제작 소프트웨어는 Windows 를 실행하는 PC 에서만 이용할 수 있다는 점을 양지하십시오.

Windows 98/Me/2000/XP 최소 사양

  • 프로세서: Intel Pentium III 또는 AMD Athlon 733 MHz CPU
  • 메모리: 128 MByte RAM
  • 하드 디스크 용량: 65 MByte 의 가용 HD 공간
  • 비디오: 16 MB NVIDIA TNT2- 클래스 또는 기타 DirectX 버전 8 에 맞는 비디오 카드 1
  • 사운드: Windows 호환 사운드 카드 2
  • DirectX: DirectX 버전 8.1b 3
  • 모뎀: 33.3 Kbps 4

Windows 98/Me/2000/XP 추천 사양

  • 프로세서: Intel Pentium III 또는 AMD Athlon 733 MHz CPU
  • 메모리: 256 MByte RAM
  • 하드 디스크 용량: 65 MByte 의 가용 HD 공간
  • 비디오: 32~128 MB NVIDIA GeForce2 또는 ATI Radeon 1
  • 사운드: Sound Blaster Audigy 시리즈의 사운드 카드 2
  • DirectX: DirectX 버전 8.1b 3
  • 모뎀: 56.7 Kbps 4

1 은 해당 장치가 DirectX 버전 8.1 또는 그 이상의 버전과 호환성이 있어야 한다는 것을 가리킵니다.

2 NVIDIA nForce 또는 Dolby Digital (돌비 디지털) 오디오에서 요구되는 Dolby Digital Interactive Content Encoder (돌비 디지털 대화식 인코더)가 들어있는 그밖의 마더보드/사운드 카드.

3 런타임의 설치에는 DirectX 8.1b 가 제공되지 않습니다. 이것이 이미 시스템에 들어 있거나 마이크로소프트로부터 다운로드되어 있어야 합니다. 자세한 내용은 EndUserDirectX81bInstallation? 을 참고하십시오.

4 모뎀은 모뎀 기반의 인터넷 복수 사용자 네트워킹에서만 요구됩니다. 인터넷 (TCP/IP) 및 LAN (TCP/IP) 복수 사용자 네트워킹도 지원됩니다.

GNU/Linux x86, Macintosh OS X

이 플랫폼들에는 런타임 소프트웨어를 사용할 수 없습니다. 이 플랫폼들에 대한 지원이 요구될 경우에는 Unreal Engine 2? 의 사용을 고려해 보십시오. 사용권 취득 정보는 Unreal Technology 사이트 에 수록되어 있습니다.

런타임의 입수

다운로드 하기

무료로 이용할 수 있는 UE2 Runtime 최신 데모 버전:

  • 다운로드: UE2Runtime-22262002_Demo.exe
  • 2004 년 11 월 23일자로 업데이트된 EULA (최종 사용자 사용권 협약): UnrealEngine2RuntimeEULAKR?

가장 최근에 등록된 UE2 Runtime (상업용) 버전:

  • 다운로드: UE2Runtime-22262002_Registered.exe
  • 등록된 EULA 는 2004 년 11 월 23 일자로 업데이트 되었으며, 다음 페이지에서 확인할 수 있습니다: UnrealEngine2RuntimeRegisteredEULAKR

UE2 Unreal Script 의 스스 코드를 입수하려면 RuntimeScripts22261903KR? 을 방문하십시오.

최신 버전의 UE2 Runtime 헤더들에 접근하려면, RuntimeHeaders22262002KR? 를 방문하십시오. UE2 Runtime 헤더들은 NDA (기밀 유지 협약)에 사인한 상업용 라이센스 사용자들만 이용할 수 있습니다.

웹 브라우저를 통해 다운로드 할 경우에는 파일을 어떻게 할 것인지에 대한 질문을 받게 될 가능성이 큽니다. Save File 또는 Save this program to disk 를 클릭하고, 파일을 저장한 위치를 기록해둔 다음 OK 를 클릭하십시오.

설치하기

  • 다운로드가 완료된 후 대화상자가 Open 또는 Launch File 옵션을 제시하면, 그 옵션을 클릭하십시오. 그렇지 않으면 Start, Run..., Browse... 및 설치 파일을 저장해둔 곳을 탐색한 다음 OK 를 클릭하십시오.
  • Setup 을 클릭하여 설치를 시작하십시오.
  • 설치 파일 압축 풀기가 끝나면 UnrealEngine2 Runtime 설치 대화상자가 나타납니다. Next 를 클릭하면 소프트웨어 사용권 협약이 나옵니다. 런타임을 이용하려면 여기에 제시된 조건들에 동의해야 합니다. 동의하신다면 I Agree 를 클릭하고 계속 설치를 진행하십시오.
  • 그 다음 화면에서는 런타임을 설치할 다른 장소를 입력할 수 있습니다. 기본 설정 위치를 사용할 것이 권장됩니다. Next 를 클릭하여 계속하십시오.
  • 런타임 소프트웨어를 1 부 이상 설치할 경우에는 2 개의 런타임 연합에 대한 체크박스의 주석을 읽어보셔야 합니다. 옵션 중 하나, 또는 두 옵션을 모두 변경할 수 있습니다.
  • 끝으로 Next , 그 다음 Install 을 클릭하십시오.
  • 설치가 끝나면 UnrealEngine2 Runtime 을 시동 하고 Release Notes (릴리스 노트) 를 읽거나 이 웹사이트를 방문할 수 있습니다.

런타임 사용하기

  • 런타임을 사용하려면 설치기의 최종 화면에서 Launch UnrealEngine2 Runtime 을 선택하여 이를 시동하거나, Start, Programs, UnrealEngine2 Runtime 을 선택한 다음 Launch UnrealEngine2 Runtime 을 클릭합니다.
  • 런타임 스플래시 스크린이 등장한 다음 메인 메뉴가 나옵니다. 런타임에는 여러분이 이리저리 둘러보면서 런타임의 콘트롤들을 익히고, 이 소프트웨어를 사용하여 만들 수 있는 가장 기본적인 효과들을 볼 수 있는, 간단한 견본 맵이 들어 있습니다.
  • Load Map 을 클릭하여 레벨을 엽니다. 마우스는 여러분의 관점을 제어합니다; 이것을 mouselook (마우스룩) 이라고 합니다. 키보드는 관점과는 별도의 움직임을 제어합니다. 여러분이 머리를 돌려 사방을 둘러보면서 걸을 수 있는 것과 같습니다. 상하 화살표 키 또는 W 와 S 키를 사용하면 전진 및 후진을 할 수 있습니다. 좌우 화살표 키나 A 및 D 키를 사용하면 왼쪽 및 오른쪽으로 가게 됩니다 (왼쪽 및 오른쪽으로 도는 것이 아니라, 가로로 이동하는 것, 즉 옆으로 내디디는 것입니다). 그밖에, F 키는 비행 모드와 보행 모드 사이를 토글합니다.
  • Esc 키를 누르면 메뉴가 나타나 레벨을 닫고 메인 화면으로 되돌아 가서 여러분의 설정을 살펴보거나 프로그램을 완전히 종료할 수 있습니다.

자세한 정보는 Getting Started? (UE2 Runtime) 을 참고하십시오.

구성하기

  • 런타임은 PC 의 하드웨어에 따라 기본 비디오와 오디오의 구성을 선택합니다. 런타임 메뉴 화면의 다양한 탭들은 이 설정들을 변경하여 렌더링의 질과 속도 사이의 상반관계를 조정할 수 있도록 합니다. EndUserEngineConfiguration? 에서 이 옵션들을 검토해 보시기 바랍니다.
  • 런타임의 구성 파일을 수동으로 편집하여 OpenGL 지원, 빠른 CPU 와 느린 비디오 카드를 사용하는 PC 용 소프트웨어 렌더링, 비디오 리프레시 동기화 및 그밖의 많은 추가 렌더링 옵션을 이용할 수 있습니다. EndUserVideoConfiguration? 에서 이 옵션들을 검토해 보시기 바랍니다.

런타임을 위한 개발

런타임 프로그래밍

런타임을 위한 여러분 고유의 기능을 작성하기 위해서는 UnrealScript 소스 코드? (version 2226.19.03) 가 필요합니다. 디버거도 이용할 수 있습니다.

런타임 프로젝트를 위해 DLL 및 인터페이스를 새로 만들고 싶다면, 등록 사용자들은 Unreal Engine 2 Runtime 을 위한 C++ native 소스 코드 헤더? 를 이용할 수 있습니다.

자신의 런타임 콘텐츠 작성하기

  • Start, Programs, UnrealEngine2 Runtime 을 선택한 다음 UnrealEngine2 Editor 를 클릭하면 UnrealEngine2 Editor (UnrealEd)가 시작됩니다.
  • UDN 의 UnrealEngine2 부분에는 레벨 디자인 과정에 대한 완벽한 문서가 들어 있습니다. WhatToReadFirstKR 는 훌륭한 출발점입니다.
    • 그밖에, UDN ExampleMapsKR? 에는 다운로드 하여 특징 및 기능들이 구현된 방법을 살펴볼 수 있는 작고 간단한 견본 맵들의 목록이 있습니다. 각 견본 맵의 “Runtime” 버전을 다운로드하는 것을 잊지 마십시오.
  • 런타임 인터페이스 커스터마이즈하기, 새 UnrealScript 코드 작성하기 및 그밖의 많은 것들에 관한 기술 문서가 곧 준비됩니다.
    • RuntimeExampleRestrictedMenuKR? 에서는 여러분 고유의 메뉴 작성법을 배울 수 있습니다.
    • MakingRuntimeInstallersKR? 를 읽으면 런타임 프로젝트를 패키지로 꾸려서 하나의 독자적 어플리케이션으로 만드는 방법을 알 수 있습니다.
  • 커뮤니티 사이트
    • http://forums.beyondunreal.com/forumdisplay.php?f=438 의 런타임용 비공식 BeyondUnreal 포럼을 방문해 보십시오.

버그 보고하기

  • 여느 최첨단 테크놀로지에서처럼, 런타임 소프트웨어도 크래시되는 경우가 있을지 모릅니다. 이런 경우에는 Submit Bug Report (버그 보고서 제출) 버튼을 누르면 대화상자가 나타납니다. 이 버튼을 사용하여 오류들을 보고해 주십시오. 한 번만 누르면 됩니다.
  • Unreal Tournament 2003 비디오 게임의 Windows PC 판을 가지고 계시다면, UT2003 을 사용하여 런타임 소프트웨어가 크래시된 과정을 재현해 주시기 바랍니다. 그러면 그 문제점이 런타임에 한한 것인지, 엔진 일반의 문제인지 판단하는데 크게 도움이 될 것입니다 .

정정

  • 메뉴에는 소개되어 있지 않지만, 런타임에는 완벽하게 작용하는 광범위한 네트워크 기능이 있습니다. 명령행에서 "ucc.exe server " 구문으로 서버를 실행할 수 있습니다. 표준 콘솔 명령을 사용하여 서버 접속을 열 수도 있습니다. 이를 시험해 보려면 서버를 실행한 다음 런타임 클라이언트를 실행하십시오. 런타임 클라이언트에서 ` (역따옴표)를 눌러 콘솔을 연 다음, "open <서버의 이름 또는 서버의 IP 주소>"를 타이프하여 서버 가운데 하나에 접속합니다. 일단 접속되면, 여기저기 돌아다니면서 다른 방문자들(큐브로서 표시되는)을 볼 수 있게 됩니다. T 를 누르고 텍스트를 입력하면 다른 방문자들과 대화를 나눌 수 있습니다.
