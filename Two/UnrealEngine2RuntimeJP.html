UnrealEngine2 ランタイム

ドキュメントの概要:リリース情報を含めた次世代Unreal engineのUnrealEngine2 Runtime エディションの紹介。

ドキュメントの変更ログ:新規作成および更新。時間をかけて維持。

概要

このページでは UnrealEngine2 Runtime ソフトウェア、ドキュメンテーション、リリースノートおよびエラッタについての情報を提供しています。

はじめに

UnrealEngine2 Runtime は、最先端のクロスプラットフォームおよび、デスクトップのリアルタイム3Dレンダリングソリューションです。Runtimeはハードの進歩に伴った3Dの最新の拡張機能を利用し、インタラクティブなウォークスルーのための安定したプラットフォームやシミュレーションを提供します。

注意:Unreal Engine 2 は、ドキュメンテーションおよび下記の推奨されたサポートチャンネル以外は、サポートされていません。

  • 非公式のディスカッションおよびサポートについては、http://forums.beyondunreal.com/forumdisplay.php?f=438 でUnrealEngine2 Runtime 用の BeyondUnreal フォーラムをご覧ください。
    • UnrealEngineRuntimeの商業用ライセンスが取得可能です。ライセンス内容に関する情報はhttp://www.unrealtechnology.com でご覧ください。
  • ランタイム特有のサポートドキュメントの目次は、 RuntimeTopics をご覧ください。
  • UnrealEngine2 Runtimeのデモバージョンは、非営利目的や教育目的での使用のみに認可されています。販売用のゲームの開発には使用できません。ダウンロードの前にご使用条件をお読みください。: UnrealEngine2 RuntimeEULA
  • 技術機能や能力については、 Engine.UnrealEngine2Featuresドキュメントをお読みください。

システム要件

Runtime クライアントおよびサーバーの利用状況の有無にかかわらず、UnrealEngine2 Editor を含めたコンテンツ生成ソフトウェアおよび　ゲームプレイスクリプト言語コンパイラーは、PC起動のWindows のみでご利用いただけます。

Windows 98/Me/2000/XP Minimum

  • プロセッサ: Intel Pentium III または AMD Athlon 733 MHz CPU
  • メモリ: 128 メガバイト RAM
  • ハードディスクスペース: 65 メガバイトの許容量
  • ビデオ: 16 MB NVIDIA TNT2-クラスまたは他の DirectX 8-コンプリアントビデオカード1
  • サウンド: Windowsと互換性のあるサウンドカード2
  • DirectX: DirectX 8.1b3
  • モデム: 33.3 Kbps4

Windows 98/Me/2000/XP で推奨されているもの

  • プロセッサ: Intel Pentium III または AMD Athlon 733 MHz CPU
  • メモリ: 256 メガバイト RAM
  • ハードディスクスペース: 65 メガバイトの許容量
  • ビデオ 32 から 128 メガバイトのNVIDIA GeForce2 または ATI Radeon1
  • サウンド: Sound Blaster Audigy シリーズのサウンドカード2
  • DirectX: DirectX 8.1b3
  • モデム: 56.7 Kbps4

1 示したデバイスが DirectX 8.1 またはそれ以上のバージョンと互換性のある。

2 NVIDIA nForce またはその他のマザーボード/サンドカードに Dolby Digitalオーディオに必要なDolby Digital インタラクティブコンテンツエンコーダ が含まれている。

3 DirectX 8.1b はランタイムインストレーションでは提供されておらず、システム上にすでにあるか、またはMicrosoftからダウンロードされていなかればならない。詳細は Technical.EndUserDirectX81bInstallation をご覧ください。

4 モデムベースのインターネット マルチユーザーネットワーキングのみに必要なもでむ。 インターネット(TCP/IP) および LAN (TCP/IP) マルチユーザーネットワーキングもまたサポートされている。

GNU/Linux x86, Macintosh OS X

ランタイムソフトウェアはこれらのプラットフォームではご利用になれません。サポートが必要な場合は、 Unreal Engine 2 の使用をご考慮ください。ライセンシーについての情報は、 Unreal Technology サイト にてご覧いただけます。

Runtime の取得

バージョンは xxxx.yy.zz 方式で ラベル化されています。 xxxx は UnrealEngine2 のバージョン、 yy はパッチレベル、 zz は Runtime のバージョンです。

UE2 Runtimeの最新バージョンは、 2226.20.02です。Runtime のデモと登録済みバージョンはここで見ることができます:

  • UnrealEngine2 Runtime 2226.20.02
  • EULAは2004年11月23日に更新され、ここで見ることができます: UnrealEngine2RuntimeEULA
  • 登録済みEULAは2004年11月23日に更新され、ここで見ることができます: UnrealEngine2RuntimeRegisteredEULA
更なる情報については Getting Started (UE2 Runtime) をご覧ください。

バグの報告

  • 最先端のテクノロジーと同様に、ランタイムソフトウェアがクラッシュする原因となるインスタンスがあるかもしれません。その問題のため、ダイアログには Submit Bug Report(バグ報告を提出) ボタンが表示されます。
  • あなたがビデオゲーム _Unreal Tournament 2003_のWindows PC バージョンのコピーを所有している場合、ランタイム特有問題なのか、それとも一般的なエンジン問題なのかを特定する助けとなるため、皆様のUT2003を使用したランタイムソフトウェアがクラッシュする原因となる操作の継続に対して、大変感謝しております。

既知の問題

エラッタ

  • ランタイムの広範囲なネットワーク性能がメニューで公開されていない時は、十分に機能しているということです。
"ucc.exe server " 構文を使用しているコマンドラインからサーバーを起動することができます。標準のコンソールコマンドを使用してサーバーにコネクションをオープンすることができます。これを行うには、サーバーを起動し、ランタイムクライアントを立ち上げます。ランタイムクライアントで ` (バッククオート) を押してコンソールをドロップダウンし、"open " (<サーバー名またはサーバーIPアドレス>を開く)と入力して、サーバーの一つにコネクトします。一度コネクトされると、動き回ったり、他のビジター(すべては立方体で表現されています)を見ることができます。ワールドにて T を押し、文字を入力して他の人と話すことができます。
