개요

본 페이지는 UnrealEngine2 Runtime 소프트웨어, 해당 문서, 릴리스 노트, 오류에 대한 정보를 제공합니다.

개요

UnrealEngine2 Runtime 소프트웨어는 크로스 플랫폼의 최첨단 프로그램으로써 데스크탑용 실시간 3D 렌더링 솔루션입니다. 하드웨어 가속 3D의 최신 발전 사항을 이용하여 Runtime은 인터액트브한 지시문과 시뮬레이션에 대한 안정적이고 강건한 플랫폼을 제공합니다.

참고: Unreal Engine 2 Runtime은 문서 및 다음 권장 지원 채널 이외의 다른 어떤 방법으로는 지원되지 않습니다.

  • 비공식적인 토론과 지원 내용에 대해서는 http://forums.beyondunreal.com/forumdisplay.php?f=438에서 UnrealEngine2 Runtime용 BeyondUnreal 게시판을 확인해 주십시오.
  • Unreal Engine Runtime의 상업 라이센스는 구입 가능합니다. 라이센스 약관에 대한 좀 더 자세한 정보는 http://www.unrealtechnology.com에서 확인해 주십시오.
  • 런타임용 지원 문서의 목차는 Runtime Topics? 를 참조해 주십시오.
  • UnrealEngine2 Runtime의 데모 버전은 비 상업적과 교육용에 대해서만 라이센스됩니다. 배포용 게임 개발은 허용되지 않습니다. Unreal Engine 2 Runtime EULA? 를 다운로드 하기 전에 라이센스 동의서를 읽고 이해해 주십시오.
  • 기술적 기능 및 성능에 관해서는 당사의 UnrealEngine2Features? 문서를 참조해 주십시오.

시스템 요구 사항

Runtime 클라이언트와 사용 가능 서버에 상관 없이 UnrealEngine2 Editor와 UnrealScript 게임플레이 스크립트 언어 컴파일러를 포함한 콘텐츠 제작 소프트웨어는 윈도우 시스템의 PC용으로만 제공됩니다.

Windows 98/Me/2000/XP 최소 사양

  • 프로세서: Intel Pentium III 또는 AMD Athlon 733 MHz CPU
  • 메모리: 128 MByte RAM
  • 하드 용량: 65 MB의 HD 공간
  • Video: 16 MB NVIDIA TNT2-class or other DirectX version 8-compliant video card1
  • 사운드: Windows 호환 사운드 카드2
  • DirectX: DirectX 버전 8.1b3
  • 모뎀: 33.3 Kbps4

Windows 98/Me/2000/XP 권장 사양

  • 프로세서: Intel Pentium III 또는 AMD Athlon 733 MHz CPU
  • 메모리: 256 MByte RAM
  • 하드 용량: 65 MB의 HD 공간
  • 비디오: 32에서 128 MB NVIDIA GeForce2 또는 ATI Radeon1
  • 사운드: Sound Blaster Audigy 시리즈 사운드 카드d2
  • DirectX: DirectX 버전 8.1b3
  • 모뎀: 57.7 Kbps4

1 표시된 장치는 DirectX, 버전8.1 이상과 호환 가능해야 합니다.

2 Dolby Digital 오디오를 위해 Dolby Digital Interactive Content Encoder가 포함된 NVIDIA nForce 또는 기타 마더보드/사운드 카드가 필요합니다.

3 DirectX 8.1b는 Runtime 설치에 포함되지 않지만 이전에 이미 시스템에 설치되어 있거나 Microsoft에서 다운로드 받아야 합니다. 자세한 내용은 EndUserDirectX81b? 설치를 참조해 주십시오.

4 모뎀은 모뎀을 기반으로한 인터넷 다중 사용자 네트워킹에만 필요합니다. 인터넷 (TCP/IP) 및 LAN (TCP/IP) 다중 사용자 네트워킹이 또한 지원됩니다.

GNU/Linux x86, Macintosh OS X

Runtime 소프트웨어는 위 플랫폼에 대해서는 사용할 수 없습니다. 위 플랫폼에 대한 지원이 필요한 경우 Unreal Engine 2? 사용을 고려해 보십시오. 라이센스 정보는 Unreal Technology 사이트에서 찾아볼 수 있습니다.

Runtime 구하기

버전은 xxxx.yy.zz 방식으로 라벨 표시되고, xxxx 는 UnrealEngine2 버전이고 yy 는 패치 레벨, zz 는 Runtime 버전입니다.

UE2 Runtime의 최신 버전은 2226.20.02 입니다. 다음에서 Runtime의 데모 및 등록 버전을 찾을 수 있습니다.

  • UnrealEngine2 Runtime 2226.20.02
  • The EULA는 2004년 11월 23일에 업데이트 되었고 Unreal Engine 2 Runtime EULA? 에서 사용 가능합니다.
  • Registered EULA는 2004년 11월 23일에 업데이트 되었고 Unreal Engine 2 Runtime Registered EULA 에서 사용 가능합니다.

좀 더 자세한 내용은 시작하기? (UE2 Runtime)을 참조해 주십시오.

버그 신고하기

  • 다른 모든 최첨단 기술에서처럼 Runtime 소프트웨어에서 충돌을 발생하는 인스턴스가 있을 수 있습니다. 충돌이 발생한 경우 Submit Bug Report (버그 신고 제출) 버튼이 표시된 대화상자가 나타납니다. 저희는 사용자 여러분께서 이 버튼을 사용하여 이러한 오류를 신고하는 것을 권장드립니다. 한 번만으로 충분합니다.
  • Windows PC 버전의 Unreal Tournament 2003 비디오 게임을 갖고 계신 경우 UT2003을 사용하여 Runtime 소프트웨어에 충돌이 발생하게 한 작업을 반복해 보셨으면 대단히 감사하겠습니다. 그렇게 함으로써 저희는 그 오류가 Runtime 전용 문제인지 아니면 일반 엔진 문제인지 구별할 수 있게 됩니다.

오류 정정

  • Runtime의 광범위한 네트워크 능력은 메뉴로 표출되지는 않았지만 완전히 사용 가능합니다. "ucc.exe server <맵 이름>" 구문을 사용하여 명령줄에서부터 서버를 실행할 수 있습니다. 표준 콘솔 명령을 사용하여 또한 서버로의 연결을 열 수 있습니다. 이것을 시도하려면 서버를 실행하고 난 다음 런타임 클라이언트를 실행합니다. 런타임 클라이언트에서 ` (역따옴표)를 눌러 콘솔을 감추고 "open <서버 이름 또는 서버 IP 주소>"를 입력하여 서버로 연결합니다. 연결된 후 자유롭게 이동하여 다른 방문자를 볼 수 있습니다(모든 방문자가 큐브로 표시됨). T 를 눌러 월드에서 얘기하고 싶은 상대방에게 보낼 문자를 입력할 수 있습니다.
