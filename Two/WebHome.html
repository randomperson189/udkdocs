Welcome to the Unreal Engine 2 Documentation

The Unreal Engine 2 was released in 2001, and last updated in 2005 before being replaced by the Unreal Engine 3, and later the Unreal Engine 4.

For reference, documentation for UE2 is provided below, but anyone interested in developing with Unreal Engine technology should use the latest available version instead.
