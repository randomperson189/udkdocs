======================================================================
UnrealEngine2 Runtime 2226.19.03 UnrealScript Source Code
======================================================================


For more information, visit the UnrealEngine2 Runtime 2226.19.03
UnrealScript Source Code web page, at:
http://udn.epicgames.com/pub/Technical/RuntimeScripts


This module contains the original UnrealScript source code files
(*.uc) used in the final 2226.19.03 release of the UnrealEngine2
Runtime.  It includes the subobjects that define the components of the
"GUI" menu system, which are not included when you manually export the
source code.
